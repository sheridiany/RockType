# RoarkT 输入法源码获取与发布要求

RoarkT 输入法是基于 Squirrel 修改的 GPL v3（或后续版本）独立程序。你可按附带 GPL 文本取得、研究、修改及重新分发源码；主 App 和服务使用各自的 MIT / 第三方许可证，不改变输入法的授权。

正式发布时，发布者必须在提供 pkg 的同一个 GitHub Release 中提供 `RoarkT-<版本>-source.tar.gz`，无需收费或额外登录即可取得，并在 Release 正文链接该文件。当前仓库地址尚未确定，这份开发安装包**尚未附上可访问的正式源码下载地址，不应作为已完成 GPL 源码交付的发行版发布**。

发布负责人需要准备和核验：

1. 与 pkg 对应的 RoarkT commit / tag，包含 `InputMethod/` 修改源码、工程与脚本、所用 MIT 共享文件和协议声明、Rime 数据、全部许可证。
2. 实际用于构建的 librime、plum 及递归依赖源码。GitHub 自动 source archive 和单独 `git archive` 都不包含子模块内容，不能代替完整源码包。
3. 预编译 librime、Lua/Octagram/Predict 插件的确切修订、补丁、静态依赖、编译参数及可用的构建说明；缺少时从记录下来的源码重建。包括 LGPL 数据的实际修订和改动。
4. 保留版权和许可证，提供构建/安装所需脚本，确认源码包中不包含密钥、证书私钥、模型权重或用户数据。签名与公证使用发布者自行持有的凭据，不应出现在源码包中。
5. 记录 pkg 与源码包 SHA-256，验证源码包能构建相同功能的输入法；同一发布同时提供二进制和对应源码，并按 GPL §6(d) 保持获取途径。

上游 Squirrel：https://github.com/rime/squirrel 。上游链接用于追溯，不替代 RoarkT 修改后版本的完整对应源码。
