# RoarkT 开发路线图

版本：v0.1。日期：2026-10-11。需求见 [PRD](prd.md)，技术决定见 [ADR-0001](adr/0001-swift-merged-product.md)。

原则：

- **UI 设计最高优先级**：每个用户可见阶段同时通过设计与功能验收，构建成功或接口返回 200 都不算完成。
- **先打通骨架，再堆功能**：签名、输入法注册、XPC 鉴权这些不可逆、难调试的部分最先做。
- **复用优先**：RoType 的 Squirrel 修改、Rime 方案、翻译协议、语音 worker、安装脚本，以及 RoarkTools 的 ObjC 原生桥（取词、OCR、钥匙串），直接迁入后再重构。RoarkTools 的 Svelte 界面与截图作为设计参考，用 SwiftUI/AppKit 重写。
- 不按日期承诺发布；M0 结束后按实测估算工作量。

## M0 工程骨架

**交付物**

- 仓库结构：

  ```
  RoarkT/
    App/            菜单栏主 App（SwiftUI + AppKit）
    InputMethod/    Squirrel 修改（GPL v3）+ librime / plum 子模块
    Core/           共享：翻译路由、AI 客户端、操作模板、设置模型、XPC 协议
    Platform/       原生能力：取词、剪贴板、OCR、截图、钥匙串、权限、快捷键
    Services/       翻译服务（XPC）、语音 worker（MLX）
    Rime/           方案、词典、Lua
    Installer/  scripts/  docs/  specs/  website/
  ```

- 新标识：Bundle ID、输入源 ID、Mach service 名、App Group、钥匙串服务名统一到新前缀（见 PRD 开放问题）。
- 一条命令完成构建与开发签名：`scripts/build.sh` 产出主 App、输入法、后台服务。
- 输入法注册到 `~/Library/Input Methods`（开发期）并可在系统中选中、打出中文。
- XPC：主 App ↔ 翻译服务、输入法 ↔ 翻译服务按签名身份鉴权的最小往返。
- 测试入口：`scripts/test.sh` 汇总 SPM 单元测试与已迁移的集成脚本。
- ADR：许可证与代码边界定稿。

**迁移来源**：RoType 的 `Squirrel/`、`Rime/`、`Shared/RoTypeXPCProtocol`、`Sources/RoTypeCore`、`Sources/RoTypeTranslationService`、`VoiceRuntime/`、`Installer/`、`scripts/`；RoarkTools 的 `internal/platform/bridge_darwin.m`、`native/translate`。迁入时全部改名，不保留旧标识。

**通过条件**：干净用户账户中构建、安装、选中输入法、打字可用；伪造签名的 XPC 客户端被拒绝；许可证 ADR 已接受。

## D0 UI 设计基线

**交付物**：可运行的 SwiftUI/AppKit 界面（模拟数据）、设计变量与组件规则、截图、交互走查记录。

- 界面：候选窗 + 译文栏、输入模式提示、菜单栏菜单、设置窗口（全部分区）、首次引导、划词工具栏、结果浮窗、截图遮罩与标注工具栏、语音 HUD。
- 覆盖浅色/深色、空态、加载、流式、成功、失败、取消、权限缺失、长内容。
- 定义交互指标数值与浮窗位置规则。
- 参考：RoarkTools `frontend/` 与截图、RoType 设置界面与候选窗。

**通过条件**：两种主题下各界面、各状态有截图；关键路径纯键盘可走通；走查问题已修正或记录。

## M1 输入法与候选翻译

- 全拼、小鹤双拼、容错、Shift 切换、英文输入、5 候选、学习菜单、模式面板。
- 统一翻译服务的离线路径（Apple Translation）与静态词条路径；候选翻译协议沿用 RoType v2（session token + generation + 原文校验）。
- Secure Input 下不请求翻译、不写缓存。
- 首次启动自动部署 Rime，学习数据独立于旧 RoType。

**通过条件**：FR-A1–A11 验收通过；翻译服务停掉时打字无变化（NFR-2）；候选窗与 D0 基线一致。

## M2 主 App 外壳

- 菜单栏（可选北京时间）、开机启动。
- 统一设置窗口全部分区（后续阶段功能先显示“即将推出”占位，不做无响应入口）。
- 首次引导：输入源真实验证、语言包、权限、AI（可跳过）。
- 权限统一归主 App；快捷键表与冲突检测；AI 连接与连接测试；本地诊断日志。
- 输入法菜单“设置”拉起主 App。

**通过条件**：FR-F1、F2、E2、E4–E7、F6 验收通过；干净账户中从安装到引导完成可走通。

## M3 划词与 AI

- 取词（直接读取 / 复制回退）、划词工具栏、快捷键、黑白名单、工具栏与窗口配置。
- 翻译、总结与追问、润色、解释、模板编辑、自定义模板、搜索、结果浮窗、复制并返回、最近结果、按功能指定模型。
- 翻译服务接入 AI 路径。

**通过条件**：FR-C1–C15 验收通过；应用兼容矩阵记录完成；真实 AI 请求经脱敏记录；NFR-5 交互指标实测。

## M4 截图

- 冻结屏幕框选、多显示器、标注全集、本地 OCR、截图翻译、图片理解、保存与复制、剪贴板与拖入图片。

**通过条件**：FR-D1–D7 验收通过；AI 不可用时本地截图与 OCR 仍可用；视觉模型不可用时本阶段不得标记完成。

## M5 语音

- 迁入 MLX 语音 worker；Fn 按住说话、HUD、模型下载与切换、自动准备、AI 润色。
- 麦克风权限归主 App；填入走输入法提交路径，Secure Input 下拒绝。

**通过条件**：FR-B1–B6 验收通过；真实麦克风与跨应用填入实测（自动化测试不能代替）。

## M6 输入法内 AI

- 候选窗 AI 动作：整句改写、润色、翻译；结果进入译文栏，Tab 上屏。
- 只在用户触发时请求；输入变化即作废。

**通过条件**：FR-E3 验收通过；AI 请求期间打字 P95 延迟与 M1 基线无差异。

## M7 分发与首版验收

- 签名、公证 pkg；卸载；Sparkle 自动更新；官网。
- 全部 FR 与 NFR 复核：P0 必须通过，未通过的 P1 写入已知限制。
- 端到端：来源应用 → 获取内容 → 真实处理 → 查看或复制 → 回到工作位置；打字 → 候选翻译 → 上屏；说话 → 填入。

**通过条件**：干净系统安装、更新、卸载全流程通过；验收报告与已知限制完成。
