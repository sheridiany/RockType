# RockType 开发路线图

2026-10-11，SPEC-014 R5-UI 同步。本文描述当前实现及剩余工作；[PRD](prd.md) 的 AC 是目标，[历史规格](../specs/README.md) 中的证据保留原时间点结论，不直接等同于当前发布状态。操作说明见[功能手册](features.md)，模块与路由以[架构](architecture.md)为准。

## 当前进度

| 阶段 | 已有实现 | 仍需完成或人工验收 |
| --- | --- | --- |
| M0 工程与进程 | Swift/Xcode 构建、签名、XPC 身份校验、独立输入法与语音 worker | 干净账户安装、正式源码交付与发布验证 |
| D0 界面基线 | 深浅色 Gallery、合成数据与离屏测试；R4-UI 已把 Gallery/Mock 限定为 debug | 真实键盘、VoiceOver、字号、多显示器与全屏走查 |
| M1 输入与候选翻译 | 全拼、小鹤、模糊音、Shift 切换、独立译文栏、Tab 上屏、词库与翻译缓存 | 真实 IMK 试打、学习持久性、跨应用光标定位与延迟 |
| M2 外壳与设置 | 12 个设置分区、权限与输入源检查、快捷键配置、单连接 AI 测试、诊断、菜单栏 | 权限授予/拒绝/撤销、输入源真实验证与开机启动 |
| M3 划词 AI | 取词、工具栏、模板、路由、流式结果、取消、追问、复制返回、会话最近结果 | 应用兼容矩阵、真实模型异常、焦点和取消竞争；多 Provider 尚未实现 |
| M4 截图 | 框选/标注/保存、贴图、本机 OCR、文字翻译、图片视觉动作、批量与剪贴板导入 | 多屏/缩放/窗口权限、真实 OCR 与视觉模型效果 |
| M5 语音 | 本地模型下载/校验、Fn 录音、HUD、ticket 填入、可选 AI 润色、术语上下文 | 真实麦克风、中英混说、首次加载和跨应用填入 |
| M6 输入法内 AI | 设置、协议、服务接口与控制器测试 | App 生命周期与 IMK 触发/作废/上屏未接线，不能宣称可用 |
| M7 分发 | 签名产物、pkg 脚本、卸载、Sparkle 嵌入与关于页入口 | 更新源/公钥、自动检查启动接线、公证、源码交付、真实安装/升级/卸载；官网发布状态待核对 |

普通启动现在打开设置。输入源启用与验证在权限页，语言包、语音模型、AI 连接按需准备；不再规划独立首次引导，不以准备步骤完成状态阻挡设置。

## SPEC-014 已合入的打磨

- 输入与语音：主题、错误与状态、词库校准、候选翻译缓存/去抖、语音本机术语上下文；合成评测不替代真实录音或试打。
- 截图与贴图：九种标注、选择/删除/撤销、每工具样式、Shift 约束、放大镜/取色、按边微调、双击复制、圆角输出、快速保存与另存；贴图缩放/锁定/穿透/透明度及会话恢复。
- OCR 与图片 AI：本机识别、编辑/高亮原图对照、原文译文并排、剪贴板/批量导入；OCR+图片的视觉翻译/总结/理解、确认、流式、取消、重试及追问入口。
- 外壳：设置逐页打磨、截图选项与贴图历史数量、快捷键速查、关于页文档、菜单入口；共享颜色与焦点样式、生产导航/原型解耦、release 不含 Gallery/fixtures。

逐轮状态与未覆盖项见 [SPEC-014](../specs/014-deep-polish.md) 和其 `evidence/` 链接；自动测试或构建通过的项目仍保留人工验收状态。

## 后续顺序

1. 在 main 的安装版本完成人工验收：输入源、权限、键盘/VoiceOver、真实语音、截图/贴图、多显示器与跨应用选择。
2. 完成 M6 接线，再验证输入变化、取消、安全输入和迟到回复；不让 AI 阻塞打字。
3. 补齐真实 AI/OCR 效果与失败场景、性能和应用兼容性记录；按实际需求推进多 Provider。
4. 发布负责人配置 Sparkle 与版本递增，完成源码材料、公证、安装/升级/卸载及官网信息核对。

各 worktree 仅构建测试，不安装、不注册输入法、不加载 LaunchAgent。正式发布必须同时通过功能、界面和分发门槛；不按日期替代验收结论。
