# RockType 功能与快捷键手册

适用：2026-10-11 已合入 SPEC-014 的开发版本，macOS 14+、Apple Silicon。本文按代码核对功能和键位；**真实键盘、麦克风、权限、跨应用与多显示器仍待人工验证**，不代表已完成正式发布验收。

`⌘` 是 Command，`⌥` 是 Option，`⌃` 是 Control，`⇧` 是 Shift，`↩` 是 Return。全局快捷键可以在设置中修改，以下列出默认值；截图、贴图和结果窗口内的键位只在对应界面处理。

## 开始使用

打开 RockType 会显示设置。没有独立首次引导，也不要求先完成全部准备步骤。后台启动不会主动打开设置。

在“权限”页查看输入源和权限状态，按提示到系统键盘设置添加 RockType Pinyin（全拼）或 RockType Shuangpin（小鹤双拼），再做真实试打验证。翻译语言包、语音模型和 AI 连接分别按需准备。菜单栏图标与北京时间显示在“通用”中开启；菜单栏图标隐藏时仍可直接打开 App 进入设置。

| 默认全局快捷键 | 动作 | 使用条件 |
| --- | --- | --- |
| 按住 Fn，松开结束 | 本地语音识别并填入 | 已下载模型、授予所需权限、使用可提交文本的 RockType 输入会话 |
| ⌃1 | 截图框选 | 屏幕录制权限 |
| ⌃⌥T | 翻译选区 | 可读取选区；离线语言包或可用 AI 连接 |
| ⌃⌥S | 总结选区 | 可读取选区及可用 AI 连接 |

全局“显示设置”默认没有绑定，可在快捷键页录制。Fn 也可能触发系统听写或切换输入源；请检查系统键盘设置，并在 RockType 查看注册状态。输入法内 AI 的设置默认值是 ⌥Tab，但触发链尚未接通，**不要将它当作可用快捷键**。

## 输入法与候选翻译

支持全拼、小鹤双拼、常用模糊音与英文补全；候选窗每页最多五个候选。候选翻译显示在独立译文栏，不占候选编号。

- 轻按左或右 Shift 切换中英，可在设置关闭；有未提交输入时会先提交当前输入。Shift 与字母组合不按轻按切换处理。
- 译文可用时按 Tab 或点击译文上屏。输入变化、候选变化或请求过期时，旧译文不能继续上屏。
- 英文短语可用单引号分隔词，提交时还原空格。
- 候选右键菜单提供学习相关操作；具体可用状态以当前候选为准。

动态候选翻译依赖 macOS 26 与就绪的 Apple 语言包；更早系统或服务不可用时按精确静态词条兜底，未命中不编造译文。当前候选翻译不自动发送到 AI。输入法内 AI 改写仍待实现接线。

**待人工验证**：真实输入应用、Shift/Tab 行为、学习持久性、候选窗位置及翻译延迟。

## 语音

在“语音”页下载并选择本地模型：默认 0.6B 8bit，也可选择 1.7B 8bit。模型准备与下载不录音；按住 Fn 才进入录音，松开后识别。HUD 显示准备、录音、识别、结果或错误。录音中约每 3 秒显示一次文字预览；预览不会提前填入，松键后以完整录音的最终识别为准。若本机处理跟不上，会暂停预览并在松键后识别。每次最长 3 分钟，到限自动结束录音并识别，长录音优先按静音处分段。录音/识别期间可按 Esc 取消。

可选 AI 润色会把识别文字交给配置的服务处理；失败时保留原始识别结果。填入只提交文字，不自动发送。来源变更、输入受保护或会话失效时会停止填入。开启自动准备后，可提前加载已下载模型。

**待人工验证**：首次加载、真实麦克风、中英混说、Fn 系统冲突和跨应用安全填入。

## 截图与标注

按 ⌃1，拖动框选；选择模式可以调整选区。放大镜显示像素与颜色。设置“截图”页可调整各工具默认颜色/尺寸、输出圆角、快速保存目录、另存格式、OCR 语言和贴图历史数量。

### 遮罩内操作

| 键位或手势 | 动作 |
| --- | --- |
| ↩ 或 ⌘C | 复制选区图片 |
| ⇧↩ | 快速保存 PNG 到设置目录，并复制文件路径；不受另存格式影响 |
| ⌘S | 另存为，自选位置与 PNG/JPEG 格式 |
| C | 复制放大镜指向位置的 HEX 颜色 |
| R | 恢复同一显示器上的上次选区 |
| P | 把选区作为贴图悬浮显示 |
| ⇧C | 本机识别选区文字并复制 |
| ⇧1 / ⇧2 / ⇧3 | 圆角矩形 / 椭圆 / 箭头 |
| ⇧4 / ⇧5 / ⇧6 | 直线 / 画笔 / 荧光笔 |
| ⇧7 / ⇧8 / ⇧9 | 马赛克 / 文字 / 序号 |
| E / V | 删除标注工具 / 选择与调整模式 |
| ⌫ 或 Delete | 删除当前选中标注 |
| ⌘Z / ⌘⇧Z | 撤销 / 重做标注 |
| 方向键 | 移动选中标注；未选中标注时移动选区，步长 1 点 |
| ⇧方向键 | 上述移动改为 10 点 |
| ⌥← / ⌥→ | 移动选区左边 |
| ⌥↑ / ⌥↓ | 移动选区上边 |
| ⌘← / ⌘→ | 移动选区右边 |
| ⌘↑ / ⌘↓ | 移动选区下边 |
| 上述按边调整再加 ⇧ | 步长由 1 点变为 10 点 |
| 滚轮 | 调整当前工具粗细；文字为字号、马赛克为颗粒大小 |
| ⇧拖拽绘制 | 矩形/椭圆等比，箭头/直线按 45° 约束 |
| ⌥拖拽绘制 | 在已有标注上叠画新标注 |
| 双击选区空白 | 选择模式下复制；双击文字标注则编辑文字 |
| Esc | 文字编辑时提交编辑；再按取消截图 |

文字编辑时由原生文本编辑器处理按键，↩ 换行，复制和撤销针对编辑文本。按边微调始终作用于选区，不调整已选标注的边。

默认输出 8 点圆角，可关闭。PNG 保留透明角，JPEG 使用白色角。只有主动保存才写文件；复制图片、复制路径与 OCR 复制文字是不同操作。

**待人工验证**：多屏/缩放、放大镜取色、标注拖拽与文字编辑、键位冲突、原生另存对话框和实际输出。

## 贴图

截图时按 P 创建贴图；拖动移动，滚轮或捏合缩放。右键菜单包含复制、另存、OCR、翻译、锁定位置与大小、鼠标穿透、透明度和关闭。

| 贴图内键位 | 动作 |
| --- | --- |
| ⌘C | 复制图片 |
| ⇧C | 本机 OCR 并复制文字 |
| ⌘⇧Z | 恢复最近关闭的贴图；需要贴图获焦，不是全局快捷键 |
| Esc | 关闭当前贴图 |
| ⌥滚轮 | 调整透明度 |

锁定后不能移动或缩放。开启鼠标穿透后，从菜单栏“退出贴图鼠标穿透”或独立“贴图”菜单恢复交互；找回的贴图也会退出穿透。

全部贴图关闭后，可从 RockType 菜单栏“找回最近关闭的贴图”恢复。历史默认 10 张，可设为 0–50 张，且总量最多 64 MB；调小立即移除最早的历史。历史仅在本次运行内，退出或“清除当前内容”后释放，不保存到磁盘。贴图没有绑定 ⌘S，另存使用右键菜单。

**待人工验证**：获焦键位、穿透退出、关闭/恢复、锁定与透明度、多显示器位置。

## OCR、图片翻译与图片理解

从截图工具栏进入“图片与文字”，或在菜单栏选择“识别剪贴板图片”“预览剪贴板图片”“批量识别图片”，也可以拖入图片。只有显式操作才读取剪贴板。

本机 OCR 使用 Vision；可在截图设置选择简体中文、繁体中文、英语、日语、韩语，至少保留一种语言。识别后可编辑文字、查看原图高亮对照、复制文字。图片预览中 ⌘R 触发本机识别，Esc 关闭预览；编辑文本时以原生编辑器的输入状态为准。

两条翻译路径要区分：

- **文字翻译**处理核对或编辑后的 OCR 文本，优先离线翻译，必要时按配置使用 AI；原文和译文可并排查看。
- **视觉翻译、视觉总结、图片理解**会发送图片与 OCR 文字，需要已验证支持图片的模型。先显示发送确认；用户可选择记忆确认偏好，也可恢复每次确认。重试会重新确认。结果支持思考/流式状态、取消、复制及转入追问。

批量识别用于本地图片文字提取；不会因为选择图片就自动发送给 AI。OCR 没识别到文字时，可换清晰图片或显式选择视觉动作。

**待人工验证**：真实图片与小字识别质量、批量文件权限、编辑对照、模型能力与发送确认、断网/取消/重试。

## 划词 AI 与结果窗口

选中文字后可用工具栏执行翻译、总结、润色、解释、搜索或复制，也可使用全局翻译/总结键。划词工具栏支持应用过滤和仅快捷键触发。密码框或安全输入状态下不取词、翻译或调用 AI。

AI 页配置当前默认服务的地址、模型及密钥；密钥存系统钥匙串。测试连接后查看文字、流式和图片能力等结果。当前代码为单个默认连接，多 Provider 管理尚未完成。操作模板可修改提示词、指定模型、恢复默认或新增模板。

| 结果窗口获焦时 | 动作 |
| --- | --- |
| ⌘L | 开始追问 |
| ↩ | 非追问编辑状态下复制结果并返回来源；追问输入框内提交问题 |
| ⌘↩ | 复制结果并返回来源 |
| C 或 ⌘C | 非追问编辑状态下复制结果；编辑时遵循文本编辑器 |
| Esc | 正在生成时先取消；追问编辑时退出编辑；其他状态关闭窗口 |

输入法正在组字时，Return/Escape 优先交给输入法。复制并返回不会模拟粘贴；回到来源后由你自行粘贴。来源失效时只复制并说明。会话最近结果最多 10 条，仅在内存保留，可以从菜单栏重新打开或清除。

**待人工验证**：跨应用选区、中文组字、焦点返回、真实模型错误、取消和追问上下文。

## 设置、隐私与更新

设置分为通用、输入法、翻译、语音、划词、截图、AI 连接、操作模板、快捷键、权限、隐私、关于。修改自动保存；快捷键页同时提供局部操作速查。设置侧栏移动焦点不会自动切页，激活按钮才切换；键盘遍历和 VoiceOver 仍待人工验证。

关于页显示版本/构建号，提供本地 MIT、GPL 与第三方声明入口及检查更新按钮。当前更新源和公钥仍未配置，按钮会说明不可用；不能据此认定已支持正式自动升级。发布和安装状态见 [分发说明](../Installer/README.md)。
