## 1. 产品定义

RockType 是 macOS 上的个人输入与 AI 工具：一个双语输入法，加一个常驻菜单栏的 AI 工具箱。两者共享同一套翻译、AI、语音、设置和权限。

用户在任何应用里：

- **打字时**：拼音或英文输入，候选旁边直接给出译文，Tab 上屏；输入法内 AI 改写仍待接线。
- **说话时**：按住 Fn 说话，本地识别后填入，可选 AI 润色。
- **阅读时**：选中文字出现工具栏，翻译、解释、总结、润色、搜索；结果浮窗里追问，复制并返回原位置。
- **看图时**：`⌃1` 截图、标注、本地 OCR、翻译或交给视觉模型。

### 核心原则

1. **不打断**：按场景管理焦点、不覆盖用户新复制的内容（显式复制除外）、打字不被网络或 AI 拖慢、Esc 回到原位。这是 UI 验收的主轴。
2. **一个产品**：一个安装包、一个设置窗口、按功能申请权限、一张快捷键表。用户感知不到“两个程序”。
3. **本地优先**：中文输入、离线翻译、OCR、语音识别全部在本机完成；只有用户显式触发的 AI 动作才发送内容。
4. **可控**：默认不落盘内容历史、不持续监听剪贴板或屏幕；Secure Input 与密码框内不取词、不翻译、不调用 AI。

### 使用场景

| 场景 | 用户动作 | 预期结果 |
| --- | --- | --- |
| 中文写作转英文 | 打拼音，看候选旁的英文，按 Tab | 英文直接上屏，不离开当前输入框 |
| 写英文不确定词义 | 输入英文单词或 `what'are'you'doing` | 候选旁显示中文释义 |
| 快速口述 | 按住 Fn 说话，松开 | 识别文字填入当前输入框，不自动发送 |
| 阅读外文 | 选中文字，点工具栏“翻译” | 浮窗显示原文与译文，复制并返回 |
| 阅读长文 | 选中后“总结”，继续追问 | 要点 + 同一上下文追问 |
| 处理报错截图 | `⌃1` 框选，识别文字或解释图片 | 本地 OCR 文本，或视觉模型解释 |
| 跨时区 | 看菜单栏 | 显示北京时间（可选） |

## 2. 系统组成（产品视角）

| 组件 | 用户可见形态 | 说明 |
| --- | --- | --- |
| RockType（主 App） | 菜单栏图标；设置窗口；划词工具栏；结果浮窗；截图遮罩 | 默认无 Dock 图标；持有全部系统权限与 AI 配置 |
| RockType 输入法 | 系统输入源列表中的“RockType Pinyin”“RockType Shuangpin” | 只负责按键、Rime、候选窗与译文栏；不申请权限 |
| 后台服务 | 无界面 | 翻译服务、语音 worker；按需启动，由主 App 与输入法通过 XPC 调用 |

输入法菜单中的“设置”打开主 App 的设置窗口。主 App 未运行时由输入法按需拉起，不抢焦点。

## 3. 交互与 UI 约定

- 先做可运行的 SwiftUI/AppKit 界面（模拟数据）作为视觉与交互基线（D0），再接系统能力与真实服务。
- 统一设计变量：排版、间距、颜色、图标、圆角、阴影、组件状态；浅色/深色主题；减少动态效果。
- 每个界面覆盖空态、加载、流式、成功、失败、取消、权限缺失、长内容等适用状态。
- 候选窗与译文栏、划词工具栏、结果浮窗、截图工具栏、语音 HUD 使用同一视觉语言。
- 交互指标（数值在 UI 基线规格中定义，实测后修订）：
  - 候选翻译：按键到译文出现的延迟；**任何翻译或 AI 请求都不得阻塞按键处理与候选刷新**。
  - 唤起：划词到工具栏可见、快捷键到浮窗可见、到第一个流式字符。
  - 按键数：“划词 → 翻译 → 复制并返回”、“拼音 → 英文上屏”。
  - 浮窗位置：靠近选区或鼠标，不遮挡选区，不越出屏幕。

## 4. 功能需求

编号沿用合并讨论时的清单：A 输入法、B 语音、C 划词与 AI、D 截图、E 统一能力、F 外壳与分发。全部功能均在产品范围内，分阶段交付见[路线图](roadmap.md)。

### A. 输入法

**FR-A1 全拼中文输入**：基于 librime，使用朙月拼音完整词库与八股文语言模型；保留用户词频学习。学习数据存于 `~/Library/Application Support/RoarkT/Rime`（独立用户目录，不读取其他输入法文件）。
AC：常用词句首选正确；词频学习在重启后保留；首次启动自动部署，无需手动操作。

**FR-A2 小鹤双拼**：独立方案“RockType Shuangpin”，与全拼共享词库与学习数据。
AC：双拼编码正确；候选顺序与全拼一致；切换方案不丢学习数据。

**FR-A3 容错输入**：全拼与双拼默认启用常用模糊音；全拼另支持简拼、拼写纠错和常见按键纠错。
AC：样本集中模糊音、简拼、纠错各项命中；纠错不压过精确匹配。

**FR-A4 中英切换与状态提示**：轻按左右 Shift 切换中英；有未上屏输入时提交已确认前缀与剩余原始输入后进入英文；Shift+字母不误切换。切换时在光标附近显示状态提示。
AC：真实 IMK 中 中→英→中 可用；提示与实际状态一致；输入框焦点切换后状态正确。

**FR-A5 英文输入**：英文单词直接输入并给出补全候选；英文短语用单引号代替空格，如 `what'are'you'doing`，上屏时还原为空格。
AC：短语上屏结果正确；英文候选不出现屏蔽词。

**FR-A6 中→英候选翻译**：当前高亮候选（整句时包含已确认前缀）作为原文，异步生成英文译文，显示在候选窗下方独立译文栏；译文不占候选编号，点击或 Tab 直接上屏。
AC：切换候选、翻页、继续输入后旧译文不显示也不上屏；译文晚到时不阻塞输入；连续快速输入无卡顿。

**FR-A7 英→中候选翻译**：英文单词或短语输入时，在译文栏给出中文释义，规则同 FR-A6。
AC：同 FR-A6；方向判定遵循“含汉字 → 中译英，纯 Latin → 英译中”，不声称识别其他语言。

**FR-A8 静态词条兜底**：动态翻译不可用（macOS < 26、语言包未就绪、服务异常）时，在同一译文栏使用人工校准的静态双语词条；按当前候选原文精确匹配，不按拼音猜词、不拼接未知句子；未命中时明确提示不可用。
AC：断开翻译服务后静态词条可用；未命中时显示“不可用”而非错误内容。

**FR-A9 候选窗**：每页最多 5 个候选；浅色/深色主题与 UI 基线一致；跟随光标，不越出屏幕。
AC：多显示器、全屏应用、屏幕边缘均位置正确。

**FR-A10 候选学习菜单**：对候选提供删除词条、调整词频（置顶 / 降权）。
AC：操作立即生效并在重启后保留；不影响系统词库文件。

**FR-A11 输入模式面板**：显示并切换当前方案、中英模式、简繁（仅简体输出时隐藏该项）等状态。
AC：面板状态与 Rime 实际状态一致；不抢来源应用焦点。

### B. 语音

**FR-B1 按住说话**：按住 Fn 开始录音，松开后本地识别（Qwen3-ASR / MLX）并安全填入当前输入位置，不自动发送。加载模型不开启麦克风；只有按住 Fn 期间录音。
AC：中文、中英混说样本识别可用；松开后文本进入原输入框；Secure Input 时拒绝填入；录音期间按 Esc 取消且不填入。

**FR-B2 模型切换**：提供 0.6B 8bit（默认）与 1.7B 8bit 两档。
AC：切换后下次识别使用新模型；内存与延迟在设置中如实说明。

**FR-B3 模型下载管理**：模型由用户在设置中下载，不包含在安装包内；显示进度、大小、校验、删除。
AC：断网、中断、磁盘不足均有提示并可重试；校验失败的模型不被加载。

**FR-B4 录音 HUD**：录音时在屏幕上显示带波形的状态 HUD：录音中、识别中、完成、失败。
AC：HUD 不抢焦点；状态与实际一致。

**FR-B5 自动准备模型**：选中 RoarkT 输入法后，按用户开关在后台预加载已下载模型，开关记住选择。
AC：开启后首次按 Fn 无冷启动延迟；关闭后不常驻占用内存。

**FR-B6 AI 润色语音结果**：可选开关：识别后经 AI 补全标点、口语转书面，再填入；失败时填入原识别结果。
AC：未配置 AI 时开关不可用并说明原因；润色失败不丢失原文。

### C. 划词与 AI

**FR-C1 跨应用取词**：优先通过辅助功能读取选区；失败时复制回退：回退前保存剪贴板并跟踪 `changeCount`，仅当剪贴板仍是本次写入时恢复。结果浮窗标明取词方式。Secure Input 或受保护输入区不取词。
AC：在兼容矩阵中分别记录直接读取、复制回退、不支持；回退不覆盖用户新复制的内容。

**FR-C2 划词工具栏**：拖选、双击、三击后在选区旁出现工具栏，不抢来源应用焦点；点工具栏外或按键即隐藏。取词方式可选“划词即出”或“仅快捷键”。
AC：TextEdit、浏览器、编辑器中工具栏出现在选区附近，来源应用保持前台。

**FR-C3 快捷键触发**：翻译 `⌃⌥T`、总结 `⌃⌥S` 等动作可直接对选区执行。
AC：快捷键冲突时显示冲突并可重设，不静默失效（见 FR-E7）。

**FR-C4 应用黑白名单**：工具栏按应用启用或禁用；Finder 默认排除。
AC：黑名单应用中不出现工具栏；设置即时生效。

**FR-C5 工具栏与功能窗口配置**：工具栏功能可启用、排序；功能窗口可跟随工具栏、自动关闭、自动置顶、调节透明度。
AC：各项设置即时生效并在重启后保留。

**FR-C6 翻译**：默认中英互译，可选目标语言；显示原文与译文并可分别复制；保留段落、列表、代码块结构。优先 Apple 离线翻译，可切换 AI（见 FR-E1）。
AC：中译英、英译中、指定语言均有实际结果；界面显示本次使用的引擎或模型。

**FR-C7 总结与追问**：默认输出中文要点；同一结果可继续追问，上下文只包含本次内容与已完成问答；“新建”不携带旧上下文。
AC：追问能引用当前内容；新建不串上下文；超长输入明确提示，不静默截断。

**FR-C8 润色与解释**：内置润色、解释两个模板。
AC：两者均有实际结果；润色结果可复制并返回。

**FR-C9 模板提示词编辑**：内置模板（翻译、总结、润色、解释）提示词可编辑、可恢复默认。
AC：编辑后下一次请求使用新提示词；恢复默认可用。

**FR-C10 自定义模板**：用户新增模板：名称、图标、提示词、适用输入（文字 / 图片）、模型、输出形式。模板只影响提示词与界面，不引入插件或脚本执行。
AC：新模板出现在工具栏并可执行；图片模板在非视觉模型下被阻止并引导。

**FR-C11 搜索引擎跳转**：用选区或编辑后的查询词，在默认浏览器打开所选搜索引擎；不经过 AI。
AC：中文、空格、特殊字符正确编码；空查询不能执行。

**FR-C12 结果浮窗**：流式显示、复制、置顶、取消、关闭、Esc；只在需要输入时成为键盘焦点；可输入追问，支持中文输入（含 RoarkT 输入法自身）。
AC：取消后不再更新；旧请求的迟到结果不影响新操作；置顶不抢占前台。

**FR-C13 复制并返回来源**：浮窗聚焦时 `↩` 或 `⌘↩`：复制结果、关闭浮窗、回到有效来源，用户自行 `⌘V`。来源失效时只复制并说明。不模拟按键回填。
AC：回到原输入位置后可直接粘贴；用户已切换应用时不被拉回。

**FR-C14 会话内最近结果**：内存保留本次运行最近 10 条结果，可从菜单栏重新打开；不落盘，退出或“清除当前内容”后清空。
AC：重启后列表为空；应用目录无内容文件。

**FR-C15 按功能指定模型**：翻译与其他功能可分别指定模型（来自同一服务商连接）。
AC：各功能实际请求使用所指定的模型，并在浮窗中显示。

### D. 截图

**FR-D1 截图框选**：`⌃1` 冻结当前屏幕，遮罩上拖拽框选并显示尺寸，选区可调整；支持多显示器。截图前隐藏自身浮窗。
AC：导出图片与框选区域一致；Esc 取消不留文件。

**FR-D2 标注**：圆角矩形、椭圆、箭头、直线、画笔、荧光笔、马赛克、文字、序号；选择、移动、缩放、删除、撤销/重做；每工具颜色与尺寸记忆。
AC：标注按原始分辨率合成；撤销正确。

**FR-D3 本地 OCR**：用 Vision 在本机识别文字，不上传；结果可编辑、复制、翻译、总结。
AC：断网可用；确认无网络请求。

**FR-D4 截图翻译**：对 OCR 文本执行翻译，结果在浮窗显示。
AC：翻译基于用户核对或修正后的 OCR 文本。

**FR-D5 图片理解**：显式动作，把截图发给已验证支持图片的视觉模型；发送前显示将发送的图片。
AC：纯文本模型被阻止并引导配置；视觉模型实际收到图片并产生结果。

**FR-D6 保存与复制**：完成复制图片；快速保存 PNG 并复制路径，或选择格式/位置另存。截图输出圆角默认开启，可在设置关闭；PNG 透明角、JPEG 白色角。
AC：剪贴板内容与预览一致；只有用户主动保存或开启截图历史磁盘保存时才写文件。

**FR-D7 外部图片输入**：显式读取剪贴板、拖入图片或批量选择图片，进入预览与 OCR；不持续监控剪贴板。
AC：两种来源都能执行 OCR、翻译、图片理解。

**FR-D8 截图历史与贴图群组（SPEC-014 R4-SURF）**：默认在内存保留本次运行最近 20 张已完成截图，串行本机 OCR 供搜索；历史支持预览、贴图、复制、保存、删除和清空。磁盘保存默认关闭，用户开启后存于 RockType 应用支持目录，按数量与天数淘汰。Secure Input 中不入库、不识别、不写缓存。贴图支持隐藏／显示全部、关闭全部与循环焦点。
AC：缺字段设置保持磁盘关闭；数量、天数、删除、退出与重启行为符合选项；卸载删除数据包含截图历史。新全局快捷键可在统一快捷键页修改、清除和检测冲突。大图按内存上限提前淘汰；真实窗口、键盘与权限仍须人工验收。

### E. 统一能力

**FR-E1 翻译路由与取消**：候选翻译使用本地精确缓存、macOS 26 Apple 离线翻译及本地静态词条兜底；当前候选路径没有 AI fallback。划词/截图文字翻译由主 App 优先请求 Apple 翻译，不可用时按配置使用 AI。图片视觉动作须显式确认。每个请求带会话与代次，取消后丢弃迟到结果。
AC：实际引擎可辨认；服务异常不阻塞输入；取消、内容变化和安全输入保护不泄漏旧结果。

**FR-E2 AI 服务商连接**：一个默认服务商：名称、Base URL、密钥、默认模型（标记是否支持图片）、可选视觉模型。首个协议为 OpenAI Chat Completions 兼容。密钥只存钥匙串。连接测试分别显示文字、流式、图片、取消是否可用。
AC：错误密钥、无权限模型、超时、限流均有可处理提示；日志不含密钥或内容。

**FR-E3 输入法内 AI**：在候选窗提供 AI 动作（快捷键触发）：对当前整句改写、润色或翻译，结果显示在译文栏，Tab 上屏。仅在用户触发时请求，不随每次按键请求。
AC：AI 请求进行中继续打字不卡顿；输入变化后旧结果作废；未配置 AI 时不显示入口。

**FR-E4 统一设置窗口**：一个设置窗口，侧栏分区：通用、输入法、翻译、语音、划词、截图、AI 连接、操作模板、快捷键、权限、隐私、关于。输入法菜单与菜单栏都能打开。
AC：所有设置即时生效并在重启后保留；设置存于 `~/Library/Application Support/RoarkT/`。

**FR-E5 设置内按需准备**：普通启动打开设置，后台启动保持安静；不设置独立首次引导。用户在权限页添加并真实验证输入源，按需准备语言包、授予权限，在语音页下载模型、AI 页配置连接。
AC：不以准备步骤完成状态阻挡设置入口；各功能缺少权限时就地说明。输入源验证基于真实按键计数而非仅检查注册状态。

**FR-E6 统一权限**：辅助功能、屏幕录制、麦克风归属主 App 一个身份；按功能说明用途并请求；未授权的功能显示原因与系统设置入口；不要求一次授予全部权限。
AC：首次、拒绝、授予、撤销四种状态均正确显示，撤销后可重新授权并重试。

**FR-E7 全局快捷键表**：所有快捷键（翻译、总结、截图、语音 Fn、输入法内 AI、显示设置等）集中配置；注册冲突时显示冲突并可重设。
AC：与系统快捷键或其他应用冲突时可发现；修改后立即生效。

**FR-E8 安全输入保护**：Secure Input 启用或焦点在密码框时：不取词、不显示划词工具栏、不请求翻译、不调用 AI、不填入语音结果、不写响应缓存。
AC：在密码框、终端 Secure Keyboard Entry 中逐项验证无请求、无缓存。

### F. 外壳与分发

**FR-F1 菜单栏**：菜单栏图标；可选显示 `北京 HH:mm`（固定 `Asia/Shanghai`），默认关闭。菜单包含：北京日期与星期、本地时间、最近结果、截图、设置、退出。
AC：系统时区与北京不同时显示正确；跨日、睡眠唤醒、时区变更后刷新。

**FR-F2 开机启动**：可选，默认关闭。
AC：设置与实际行为一致。

**FR-F3 签名、公证与安装包**：一个签名、公证的 pkg：安装主 App 到 `/Applications`，输入法到 `/Library/Input Methods`，注册后台服务。安装器只注册输入法，不静默启用或选择输入源。卸载入口在设置中，删除程序并可选删除用户数据。
AC：干净系统上安装、设置内准备、卸载全流程通过；Gatekeeper 无警告。

**FR-F4 自动更新**：Sparkle，更新主 App 与输入法；更新后输入法进程正确重启。
AC：从上一版本自动更新成功，学习数据与设置保留。

**FR-F5 官网**：介绍、下载、隐私说明、更新日志。
AC：下载链接指向最新签名版本。

**FR-F6 诊断**：本地日志只记录动作类型、状态、耗时与脱敏错误；用户可主动导出诊断包。
AC：导出内容无原文、截图、密钥、查询词；日志有大小与保留期限。

## 5. 非功能需求

| 编号 | 要求 | 验收 |
| --- | --- | --- |
| NFR-1 隐私与密钥 | 默认不持续监听剪贴板或屏幕、不保存内容历史；只有显式 AI 动作发送内容；密钥只在钥匙串 | 核对网络请求、文件、日志、钥匙串 |
| NFR-2 输入性能 | 按键处理与候选刷新不等待任何网络、翻译或 AI；候选翻译异步 | 固定样本测量按键到候选的 P95 延迟；翻译服务停掉时打字无变化 |
| NFR-3 性能与功耗 | 记录启动、唤起、取词、截图、首字延迟、空闲 CPU/内存；语音模型未启用时不常驻 | 固定硬件与样本实测；空闲 5 分钟平均 CPU ≤ 1%（暂定） |
| NFR-4 错误与取消 | 区分权限、网络、认证、模型能力与输入限制；取消中止本地任务与网络请求；迟到结果不改变新操作 | 断网、超时、401/403、限流、取消均可恢复 |
| NFR-5 应用兼容 | 按应用记录取词、输入法、浮窗的支持情况 | 至少覆盖默认浏览器、代码编辑器、企业微信、PDF 阅读器、全屏窗口、多显示器 |
| NFR-6 键盘与可访问性 | 主要流程纯键盘可用；控件有可识别标签；VoiceOver 与系统字号下可读 | 键盘走查与 VoiceOver 检查 |
| NFR-7 UI 设计质量 | 最高优先级；所有界面与基线一致、主题与状态完整 | 每个增量附截图与走查记录，设计验收未过不得完成 |
| NFR-8 进程隔离与鉴权 | 输入法、主 App、翻译服务、语音 worker 之间只通过 XPC 通信，并按签名身份鉴权；输入法进程只做输入 | 伪造客户端被拒绝；任一后台进程崩溃不影响打字 |
| NFR-9 许可证合规 | 输入法进程（Squirrel 修改）按 GPL v3 提供源码；其他组件许可证由 ADR 确定；第三方声明完整 | 发布前核对 THIRD_PARTY_NOTICES 与源码包 |

## 6. 不做

- 云端语音识别、免提录音、自动发送。
- 自动回填（模拟 `⌘V` 写入来源）、未经开启的内容历史落盘、剪贴板管理。截图历史的显式磁盘保存见 FR-D8。
- 网页滚动长截图。
- 带来源引用的 AI 联网搜索（需独立规格）。
- 小鹤以外的双拼方案。
- 多服务商连接管理、插件系统、知识库、多设备同步。
- Windows、Intel Mac 的正式支持。
- 旧产品的升级迁移。
