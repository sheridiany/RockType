## F1 无感进入（pi-xpc）

- 现象：按 ⌃1 进入截图时画面整体“动一下/晃一下”。先定位原因再改，可能来源：遮罩窗口出现时冻结帧与真实屏幕有缩放/像素对齐偏差（Retina backingScale、坐标取整、菜单栏/刘海偏移、多屏原点）；窗口淡入动画；先显示空窗再填图；遮罩变暗过渡；光标切换；窗口 level/Space 切换导致的闪烁；SCK 截帧前隐藏/显示其他窗口。
- 目标（参考 Snipaste / PixPin / CleanShot X / macOS 自带 ⌘⇧4）：冻结帧与屏幕逐像素重合，出现瞬间无位移、无缩放、无闪白/闪黑、无淡入动画；变暗遮罩可以直接出现或 ≤80ms 极短淡入，但底图不得移动。
- 验证：离屏/自动化比较冻结帧与同一时刻屏幕截图的像素偏移为 0（含 2x、多屏原点非零的合成用例）；记录根因写进证据。真实观感待人工。
- 不要动工具栏图标和标注样式（F2/F3 负责）。

## F2 选区框与图标粗细（pi-ui）

- 选区边框：现在太细，改为约 2pt（Retina 下清晰，不发虚），颜色用强调色或白+细暗边保证在任何背景上可见；8 个调整手柄同步加大、实心、对齐。参考 Snipaste/PixPin 的选区边框。
- 工具栏图标：SPEC-015 I1 改得太粗，回调到中间：符号权重 `.medium`（不用 `.bold`/`.fill` 大面积实心，马赛克/橡皮擦等实心图标换描边版或降一档），图标约 14pt；选中态保留实色底；完成按钮保留强调色底。
- 顺带修正工具栏 OCR 与取消之间多余空隙和双分隔线。
- 只改 `ScreenshotSymbols`、`CaptureToolbar` 与选区边框/手柄绘制相关代码；离屏渲染新旧对比放 `.build/f2/`。

## F3 文字标注（pi-surfaces）

- 现状：红字外包一圈白描边，糊、花。
- 参考 CleanShot X / Snipaste / PixPin / Shottr / 微信截图的文字标注做法，选一个最清晰简洁的方案，倾向：默认纯色文字 + 极淡阴影（不描边）；可选“背景”样式（文字放在所选颜色的圆角实底上，文字自动黑/白反色），工具栏一键切换；字体用系统粗体（semibold），抗锯齿清晰。
- 编辑中与提交后的渲染一致；导出图片与屏幕所见一致；深浅背景上都清楚。
- 离屏渲染各颜色在亮/暗/复杂背景上的对比图放 `.build/f3/`。
