# SPEC-014 · R2-AI · pi-platform

状态：实现、全部自动化测试、签名构建和真实 Magpie 冒烟通过；真实桌面交互待人工验收。

开工在 `agent/platform` 执行 `git merge main`（Already up to date）。本轮主规格只更新 R2-AI 状态行。本机没有安装/注册/启动输入法，没有加载 LaunchAgent，没有投递全局按键，也没有从 shell 启动主 App 二进制。所有图像、文字与窗口测试使用程序生成的合成内容；未采集真实选区或屏幕，也未记录用户文件内容及密钥；真实冒烟仅读取已有连接配置和钥匙串凭据，在内存使用。

## 交互与取舍

采用 `emil-design-eng` 的高频交互与减少动态效果原则；保留原生 AppKit/SwiftUI，不增加 Markdown 或前端运行时依赖。

| Before | After | Why |
| --- | --- | --- |
| 工具栏有装饰图标占位，按选区起点摆放 | 移除装饰占位，保留用户动作顺序；靠近松开鼠标处，在选区上下左右寻找不遮挡位置并约束到当前显示器 | 减少鼠标距离，更多操作保留文字标签 |
| 划词等待 AX 更新后显示，安全状态仅在动作时检查 | 保留鼠标松开后的 90 ms 稳定等待，快捷键立即执行；显示前及显示期间也检查保护状态 | 不增加输入等待，不让过期选区/受保护内容继续显示 |
| 显示/隐藏都是瞬变 | 鼠标工具栏用 100 ms 透明度淡入，减少动态效果时即时显示；隐藏与键盘操作保持即时 | 不加入位移、弹跳或妨碍点击的动效 |
| 流式内容按每个 delta 更新、普通 ScrollView | 首段立即显示，后续按 33 ms 合并；原生滚动视图只在底部附近跟随，向上阅读保持位置，可回到最新内容 | 降低重排频率，长回答不抢阅读位置 |
| 答案纯文本 | 标题、行内 Markdown、段落与列表保留；围栏代码等宽横向滚动、独立复制，未闭合代码围栏也可显示 | 流式与长代码均可读；整体复制保留原始 Markdown |
| 单行追问，Return 提交 | 原生多行编辑器，Return 换行、⌘Return 发送；有 marked text 时交还输入法 | 中文组词不会误发送或误关闭；⌘C 交给原生选中文字 |
| 新操作关闭旧窗口，任何设置变化重设置顶 | 置顶窗口可独立并发，最多四个；普通窗口仍复用；无关设置变化不取消手动置顶 | 明确控制并发数量，取消一窗不影响另一窗 |
| 窗口固定大小，每次重新放置 | 可调整大小、标题区拖动；只保存窗口几何，关闭“跟随工具栏”后恢复位置，屏幕变化后约束到可见范围；有置顶结果时优先避让其他结果窗口 | 保持用户布局，同时不把选区或内容写入偏好 |

几何使用标准 UserDefaults 的单独键保存四个数值，不保存来源应用、内容、模型答案或图片。跟随工具栏开启时继续优先定位选区，只沿用记忆尺寸；关闭后恢复完整位置。Markdown 支持标题、行内强调/链接/代码和围栏代码；复杂表格与引用保留可读原文，不做浏览器级排版，不加载远程图片、不执行 HTML。生成链接仅允许用户显式打开 HTTP/HTTPS，禁用 file/custom scheme。

## Provider、路由与保护

- 增加服务商配置的添加、切换、改名、移除；各 profile 用独立稳定 id 对应钥匙串 account，不复制密钥。默认服务商复用原 `settings.ai`，其他配置放在新增可选数组；不存在新服务端、插件系统或数据迁移。
- 按翻译、助手（总结/润色/解释/追问）、图片、InputAI 选择服务商及模型。空任务配置跟随默认；现有按功能模型字段继续生效，模板模型仍优先。删除服务商后保留悬空任务引用并明确提示重新选择，请求在读密钥前失败，绝不静默改发其他服务商。
- 新增连接时提供本机 Magpie 地址及 `workbuddy/glm-5.3-flash` 推荐值；图片跟随该默认模型或用户显式视觉模型。没有改写用户当前设置、默认模型或钥匙串。
- 备用模型字段默认空。仅用户填写时、同一服务商内、未生成正文且出现网络/超时/临时服务器错误/限流/无正文/模型不存在时最多回退一次。认证错误、取消、格式错误、输出截断、已生成部分答案不回退；不自动填写 `claude/claude-haiku-5-5`。文字结果标明实际服务商、模型和备用使用情况，图片服务回报实际模型。
- 图片备用模型必须额外通过合成图片探针；连接测试显示其独立验证结果。验证记录绑定完整连接配置、模型集合和当前密钥摘要；切换服务商不覆盖其他记录，观察到密钥变化/配置变化后撤销记录，恢复旧密钥也不能复活已撤销验证。没有把验证状态落盘。
- `AIClient` 新增发送许可闭包，在第一次请求、每次 HTTP 自动重试前检查；选择操作还检查 generation，截图检查保护状态，InputAI 检查系统 Secure Input。回退和 OCR 后再检查，不仅依赖 UI 或后台轮询取消。密码/焦点无法安全检查时，生产选区与结果路径仍拒绝发送。
- `ScreenshotSession` 只做服务接线：根据图片任务路由选连接、读取该连接密钥；现有图片理解可携带用户修正后的 OCR，备用模型须验证并回报实际模型。预览布局、翻译/总结入口仍属于 pi-surfaces，没有接管这些 UI。
- InputAI 同步专用任务连接、模型、钥匙串凭据和显式备用模型；输入法只通过既有签名 XPC 请求。设置补齐当前模型、等待上限和配置缺失提示。服务在排队任务真正执行前、备用请求前再次检查保护；继续打字失效、generation、Esc、Tab 和输入线程的既有隔离保持不变。
- 追问仅携带完成轮次，首轮操作提示词不再作为“用户问题”出现在历史气泡里。重试会回到该请求原来的上下文，取消首轮重试后不会把已替换的旧答案偷偷带入下一次追问。
