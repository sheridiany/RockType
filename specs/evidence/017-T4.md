## 任务与接口

- [x] `AVSpeechSynthesizer` 系统声音朗读、本机语言检测、可观察播放/停止状态。
- [x] 全进程同一时间一段朗读，替换/取消/迟到回调不会恢复旧播放。
- [x] 按钮所属 NSWindow 关闭、视图消失/拆卸、服务释放时停止。
- [x] Tokens 小按钮、help/可访问性、深浅色、减少动态效果预览。
- [x] 完整 test/build 真实退出 0；真实音频、系统声音缺失及 T8 集成待人工。

供 T8 使用：每个翻译窗持有一个 `@State private var speaker = TextSpeaker()`，放入 `SpeakButton(speaker: speaker, text: translatedText, language: targetLanguageCode)`。`language` 为可选 BCP-47 编码（nil/auto 为自动检测），不是显示名“中文”。服务为 `@MainActor @Observable`，方法 `speak(_:language:)`、`stop()`；`state` 为 idle/preparing/speaking/failed，`isActive` 包括准备中，`isSpeaking` 仅实际开始后的状态，`notice` 是失败的用户说明。

按钮自带 NSWindow 关闭观察、文本/语言变化停止和 onDisappear 停止。**若 T8 的“关闭”只是 `orderOut` 并保留整个 host，必须在该关闭路径显式调用 `speaker.stop()`**；这属于阶段 B 的接入责任，不能用单独组件的生命周期测试冒称实际翻译窗已接入。多个窗口用独立实例，服务通过弱引用协调停止上一实例；关闭非当前窗口不会停止别处的新播放。

## 实现

- `TextSpeaker`：本机 `NLLanguageRecognizer` 检测前 2048 字符，显式语言优先；按精确语言地区、同语言声音、质量与稳定顺序选声。zh-Hans/zh-Hant 分别偏好 zh-CN/zh-TW。无同语言声音则说明不可用，不偷偷换成其他语言。空文字不播；最多 32000 UTF-16 单元，不截断朗读。
- `SystemSpeechDriver`：只枚举 Apple 系统声音，排除个人、趣味和第三方扩展声音；不下载声音、不请求个人声音或麦克风权限、不写音频。新播放先立即停止旧 synth，使用普通文本 utterance，不解释 SSML。
- 每次播放一个 UUID。原生 delegate 只将不可变请求 ID/事件送回 MainActor，不跨 executor 传非 Sendable 的 utterance 或 synth。停止先作废请求，旧开始/完成/取消事件不能污染新状态。
- 默认保护门禁为 `SecureInput.status() == .allowed`；开始、回调和播放期间检查，200ms 检查周期。受保护/无法确认状态即停止；准备超过 10 秒且无开始回调则恢复为可重试错误。已开始的长朗读不受启动超时影响。
- 播放内容不写日志、缓存、文件或历史；状态不保留一份源文本，文本只交给本机 utterance。假播放器测试仅使用程序合成内容。
- `SpeakButton`：14pt 图标、28pt 控件高度，播放中显示强调色停止按钮；空文字禁用；不可用有独立图标和具体 help；可访问性分别说明准备/朗读/停止。复用 `DesignButtonStyle` 的 120ms 悬停与系统/预览“减少动态效果”，不新增窗口快捷键或抢焦点。
