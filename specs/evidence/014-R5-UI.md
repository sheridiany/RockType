## 键位核对

全局：Core/Shortcuts、HotkeyCenter；输入法：SquirrelInputController 的 Tab 分支与方案 Shift 绑定；语音：VoiceInputController 的 Esc；截图：CaptureKeyboard/ScreenshotTool/CaptureCanvas/CaptureGeometry；贴图：PinnedImageView；结果：ResultWindowController 与追问输入框 onSubmit；预览：ScreenshotPreviewContent 的 ⌘R/onExitCommand。

明确区分：C 取色 / ⇧C OCR / ⌘C 图片；⇧↩ 快速保存路径 / ⌘S 另存；Option 左上边 / Command 右下边；贴图 ⌘⇧Z 是局部恢复且没有 ⌘S；结果窗 Return 与 Esc 随编辑/生成状态不同；输入法 ⌥Tab 只是未接线设置，未写作可用功能。手册相对链接经逐一存在性检查。
