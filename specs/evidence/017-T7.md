# SPEC-017 T7 · 翻译延迟、短文本缓存与字面内容保护

基线 main `ca70071`，接续 T6；交付前还会按用户要求合并含 T5 的 main 并重跑完整门禁。关联 FR-C6、FR-E1/E8、NFR-1/3/4。

## 实现与边界

- `OperationsEnvironment` 持有仅内存的 `TranslationResultCache`，跨结果窗复用；清除当前内容/停止环境时清空。只有初次翻译、无追问和历史上下文、原文 ≤500 字且 ≤4096 UTF-8 字节才缓存。
- 键包含原文、完整语言配置及解析后的目标语言（当前源语言自动检测）、实际 Apple/AI 引擎、实际模型、完整连接配置、解析后的提示词和保护协议版本。备用模型独立键，不把 AI 结果冒充 Apple。
- LRU 默认 64 条，键和值有效载荷预算 512 KiB；有效期 5 分钟，访问/插入时淘汰过期项。取消、失败、缺失占位符和受保护输入不入库；命中前同样检查保护，保护拒绝时清空缓存。缓存不含凭据、不落盘。
- AI 翻译在发送前保护 fenced/缩进代码块、行内代码、URL；模型仅看到随机占位符，流式返回时跨分片还原原始字节。未知、重复、缺失或畸形占位符拒绝完成，不缓存损坏结果；最多 512 段保护内容，超出时失败，不默默漏保护；URL scheme 识别上限 32 个 ASCII 字符。
- 同一个 runner 懒创建并复用无磁盘缓存、无 Cookie 的 URLSession；没有后台预发网络请求。备用模型继续使用同一次操作的凭据快照。
- 新增 `translation_first_text_ms` 数值日志及 `onFirstText` 回调，区分 Apple / AI / cache / segmented。只记录耗时和类别，不含选区、输出、模型私有配置或凭据。窗口 UI 未修改。
