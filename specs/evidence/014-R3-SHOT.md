## 实现边界

- `Platform/CaptureAccessibility.swift`：在后台读取捕获开始时鼠标坐标对应的最前外部窗口，通过**应用级** AX 根节点命中元素，不会误命中随后出现的本应用遮罩。只读取 role / subrole / position / size / parent / children；不读取文本值、标题、描述、选区或 URL。不保留 AX 对象，也不把实际几何写入日志。
- 每条 AX 消息最多 20 ms；一次遍历预算 100 ms；主线程接收截止时间 120 ms。应用挂起或窗口服务器迟缓时，遮罩继续走像素截图流程；单个查询控制器最多一个后台任务，不因连续截图累积队列。取消、超时及新 generation 都会丢弃迟到结果。
- 从命中元素向上最多 12 层，并在最近 4 层各读取最多 16 个子节点，最多保留 64 个不同矩形。**这是捕获时的局部快照，不是遍历整棵应用树**。快照覆盖范围内悬停选最小包含框；范围外、窗口几何与冻结窗口不符、应用 AX 不支持时回退窗口。这样不必在冻结画面上继续读取变化后的真实界面。AX 与像素采集并非原子同步；这段时间内自行变化的布局仍需真实应用走查，不声称所有动态页面都精确命中。
- 快照转换到各屏幕的左上角逻辑坐标，保持 Retina 像素与逻辑点分离；父级框裁切在所属窗口 / 显示器内，遮挡窗口不会选到背后的元素。相同框去重，重叠但不包含的框不作为父级。
- 未确定选区时，Tab / 滚轮正向扩大到父级，⇧Tab / 滚轮反向缩小；到端点不循环。同一元素内小幅移动保留所选层级，移到另一元素重新选最小框。单击确定，拖动仍自由框选；拖选开始或已有选区后，迟到快照不会更改选区。确定后 Tab 交还 AppKit 焦点导航，文字输入仍保有按键所有权。
- 查询开始、每条消息前和发布前检查 Secure Input / AX 权限；发现安全文本字段停止并丢弃快照。消息超时只设置在目标进程的元素上，不修改系统级 AX 全局超时。
- 原截图入口把无 AX 权限也当成拒绝截图。本轮只对**屏幕截图、复制图片 / 色值、保存**允许 `.noPermission` 回退；`.secureInput` 与可授权但焦点无法检查的 `.unavailable` 仍拒绝。取词、AI、OCR 预览、贴图继续使用原有严格保护；这些入口不可用时保留当前选区并提示。未修改 `SecureInput.status()` 或通用剪贴板保护。
- 空的 `CaptureAnnotationView` 不再显示并绘制整屏透明 backing layer。有草稿 / 标注 / 选中边框时显示；撤销至空隐藏，重做恢复。保留冻结图片层和既有标注绘制方式。

AX 接口行为核对来源：本机 macOS SDK `ApplicationServices.framework/Frameworks/HIServices.framework/Headers/AXUIElement.h`，`AXUIElementCopyElementAtPosition` 支持应用级根与左上角坐标；`AXUIElementSetMessagingTimeout` 的系统级根会改变全局超时，因此本实现不用系统级根查询。

### 可重复性能对照

`CapturePerformanceTests.testSyntheticOverlayLatencyAndFootprint` 是显式开启的基准。每组单独启动测试进程，7 次样本。基线先于本轮生产代码修改取得；修改后使用相同测试与命令。每份输入为独立、程序生成的 1920×1080 逻辑图像，1× 或 2× 像素；两份输入模拟两屏，不共用图像。面板置于所有实际屏幕之外、忽略鼠标、不取键盘焦点，测试后立即关闭。

计时范围为 `CaptureCanvas` / `CapturePanel` 创建、挂接、显示准备和 `CATransaction.flush()`；不含 SCShareableContent、ScreenCaptureKit 像素采集、系统安全焦点检查、AX 遍历、物理屏幕合成显示。**该指标叫合成遮罩准备耗时，不能当作完整 `overlay_ms`。** 内存为 `task_vm_info.phys_footprint`；冷增量指首个面板准备前后增量，输入图像已准备。暖态内存会受分配器复用影响，不能解释为零内存需求。

| 合成输入 | 准备中位 ms：前 → 后 | 最大 ms：前 → 后 | 冷增量 MiB：前 → 后 |
| --- | --- | --- | --- |
| 1 份，1×，1920×1080 像素 | 10.31 → 8.83 | 42.03 → 37.81 | 36.09 → 28.27 |
| 1 份，2×，3840×2160 像素 | 30.65 → 27.82 | 57.27 → 57.02 | 107.20 → 99.27 |
| 2 份，均为 2× | 57.51 → 55.96 | 91.04 → 83.83 | 178.70 → 163.02 |

空标注层优化减少每个测试面板约 7.9 MiB 冷增量；两份 2× 输入约减少 15.69 MiB。7 个样本不足以给出稳定 P95 或统计显著性结论。它验证了空层开销降低，不能证明不同真实应用和多屏配置的完整延迟绝不退化。

复现（分别以 `1x1`、`1x2`、`2x2` 运行）：

```sh
ROARKT_SHOT_BENCHMARK=1 ROARKT_SHOT_BENCH_SCENARIO=2x2 \
  swift test --filter CapturePerformanceTests.testSyntheticOverlayLatencyAndFootprint
```

本机元数据：1 块 1728×1117 逻辑分辨率、2× Retina 屏；测试宿主的屏幕录制与 AX preflight 均显示已授权。实际尝试完整链路时，安全焦点检查返回 `unavailable`，因此 `testLiveRetinaOverlayMetrics` 在采集前跳过。**有权限不代表焦点检查成功，这次不能填写真正的 `overlay_ms` 前后值。** 实际双屏硬件也不存在，不能把合成两屏记为物理双屏通过。

保留一个显式 opt-in 的真实测量入口：在可通过焦点保护检查的测试宿主上，先令 `ROARKT_SHOT_LIVE_AX=0`，再令其为 `1`，各运行 9 次实际采集，记录既有 `overlay_ms` 边界和进程 footprint；显示回调立即取消遮罩，不保存图片。默认全量测试跳过此项，不读取真实桌面。

```sh
ROARKT_SHOT_LIVE_BENCHMARK=1 ROARKT_SHOT_LIVE_AX=1 \
  swift test --filter CapturePerformanceTests.testLiveRetinaOverlayMetrics
```

本地原始数字日志：`.build/r3-shot/before-{1x1,1x2,2x2}.log`、`after-{1x1,1x2,2x2}.log`；真实尝试状态：`live-no-ax.log`、`live-ax.log`。最终全量验证日志为 `.build/r3-shot/test.log`、`build.log`，对应 `.exit` 文件均为 `0`；默认全量测试跳过两项 opt-in 性能基准，合成基准已另外执行，真实基准的阻塞如上。不提交这些临时文件；无屏幕内容、用户文本或 AX 节点身份落盘。

## 滚动长截图设计与进度

本轮用户将滚动长截图列为可选扩展；PRD 原“不做”列表尚未调整。当前仅设计，下一轮另列实施任务后再启用。没有 `L` 快捷键、会话状态或拼接半成品混入现有截图路径。

1. **入口与来源绑定**：确定选区后按 `L` 进入（拟定，不占现有按键；文字编辑时不拦截）。绑定捕获来源 PID / window ID、显示器、逻辑选区、像素比例和 generation。屏幕布局、来源窗口或比例变化即结束，不把不同来源拼在一起。
2. **先做手动滚动**：隐藏冻结遮罩，显示独立小型、不激活的控制条。用户在来源应用自行滚动，点击“采集下一屏”；不发送全局按键或滚轮。仅显式操作采集像素，每次确认 Secure Input / 来源 / 权限，控制条不入图。首版不做后台轮询截图，也不先接自动滚动。
3. **纵向重叠与失败处理**：用下采样亮度条带寻找上一帧底部与新帧顶部的重叠，再按原始像素细化位移。需要足够重叠与唯一匹配；重复行、动画、横向位移、固定头部造成歧义时保留已有结果并提示重新采集 / 调整选区，不能悄悄拼错。不变帧不追加；提供撤销最后一段。
4. **明确上限**：暂定最多 32 帧、最终高度 30,000 像素、解码像素工作预算 128 MiB，任一先到即停止继续采集并允许完成已有结果。记录最末完整帧与去重后的条带，避免同时保留所有完整图像；容量计算须含源帧、合成缓冲和编码峰值。只在用户保存时落盘，不借临时文件保存屏幕内容。
5. **完成与取消**：完成后只做一次最终圆角 / 编码，复用现有预览和另存为。Esc / 取消 / 保护状态变化丢弃所有未提交像素，迟到帧按 generation 丢弃。自动滚动作为后续独立能力，不能在匹配失败时持续驱动来源应用。
6. **启用门槛**：程序生成长页（中文 / 等宽代码 / 重复行 / 固定头部）、无重叠、重复帧、双向滚动、缩放变化、保护与取消、像素及内存上限测试；真实浏览器 / 编辑器滚动、Retina 与多屏走查。全部完成前保持默认路径无入口。
