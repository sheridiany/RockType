# SPEC-015 I1 · 截图图标统一

日期：2026-10-11。分支：`agent/xpc`。开工 `git merge main` 快进到 `e55c8da`。范围对应 FR-D1/D2/D6/D8、NFR-6/7。

## 实现

- 新增 `ScreenshotSymbols`，集中截图工具与动作的符号名称、15pt 字号及 AppKit 图像配置。`ScreenshotIcon` 使用 bold、单色、18pt 图标布局格；`ScreenshotLabel` 统一图文标签。装饰图标不重复朗读，按钮保留中文可访问性标签、提示及快捷键。
- 工具栏图标按钮为 **32×30pt**，选中工具为前景色实底加反色图标，完成/复制为强调色实底；取消保持中性。禁用态、悬停/按下和键盘焦点有区分，没有新增动效。
- 工具栏用不透明卡片底、**10pt 圆角**、竖向分组线。取消与完成固定在右侧；窄画布下工具区可横向滚动，不把完成按钮滚出视野。颜色、粗细、选区/标注、快捷键和输出行为不变。
- 覆盖 CaptureToolbar、标注工具映射、DEBUG 编辑器及图片预览原型、正式预览与 OCR/AI/覆盖翻译/条码/导入/批量子面板、贴图状态栏与原生菜单、历史、长截图 HUD。生产绘制的标注像素不改动。
- 预览增加直接可见的强调色“复制图片”，调用原有复制流程；原有图片操作菜单保留。文字/译图复制主按钮统一强调色。贴图菜单沿用原 selector、启用状态、勾选状态与群组动作，仅增加统一图标。

## 符号与 macOS 14

逐项读取 Apple 随系统提供的 `/System/Library/CoreServices/CoreGlyphs.bundle/Contents/Resources/name_availability.plist`，用 `symbols → year_to_release → macOS` 核对首次引入版本不高于 **14.0**；另逐项通过 AppKit 加载带 15pt bold 配置的 NSImage。应用运行时不读取此清单、不调用私有 API。此处是官方元数据核对与当前主机加载验证，不等于 macOS 14 实机视觉走查。
