# SPEC-018 W1：静态官网与部署准备

日期：2026-10-12。工作分支 `agent/ui`；开始前合并 main `33f0329`。实现已完成，原生浏览器截图与发布环境验收尚未完成；未 push、未部署。

## 做了什么

- `website/` 首页、隐私、开发进展/更新日志、404；原生 HTML/CSS/少量 JS，1120px / 12 列布局、360px 起的移动排版、系统深浅色、可暂停九条波形与减少动态效果。
- 候选/译文、语音胶囊、翻译窗、划词栏、截图选区工具栏、模型设置都来自真实生产视图离屏渲染。新增 `Tests/SurfaceTests/W1WebsiteRenderingTests.swift`；输入法仅扩展自身隔离测试的可选渲染，不将 GPL 代码引入 MIT App。
- 中文为主的功能叙述，下载 CTA 指向指定 GitHub Releases；说明下载尚待发布确认。没有编造用户评价、评分、版本、速度或 OCR 精度承诺。离线翻译系统要求、AI 发送条件与本地保存边界写入正文。
- `https://type.roarkist.com/` 统一 canonical、OG、robots、sitemap；新作 1200×630 OG。16 张图片合计 **333,309 bytes**，最大 OG **78,465 bytes**，全部 <300KB。
- `website/deploy/nginx.conf` 是 Rocky Linux 9 共享 nginx 的独立 HTTP bootstrap vhost，目标 `/etc/nginx/conf.d/type.roarkist.com.conf`；certbot `--nginx` 管理 TLS，正常更新不覆盖配置。
- `scripts/deploy-website.sh` 使用操作者提供的 `DEPLOY_HOST` / `DEPLOY_KEY`、严格 known_hosts、本站锁、SHA-256 校验、`releases/<UTC 时间戳>` / `current` 原子软链、`nginx -t`、回环 HTTP/HTTPS release 校验与失败恢复。只在首次 bootstrap 时 reload；不操作其他站点，不上传安装包，不自动删除旧 release。
