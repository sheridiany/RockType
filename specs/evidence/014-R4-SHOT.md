## 用户流程

1. 将要滚动的来源窗口置于前台，`⌃1` 后框选它内部的内容区域，按 **L**。选区须在同一窗口、同一显示器内，至少 32×32 逻辑点。已有标注时先撤销；文字编辑或拖选尚未结束时不进入。
2. 冻结遮罩关闭，来源应用恢复前台，显示不激活、不取键盘焦点的控制条。用户在原窗口手动向下滚动。控制条显示当前高度和拼接缩略图；不需要逐帧点击采集。
3. 重复内容无法确定偏移、重叠不足或反向滚动时，保留最后接受的图片，不增加高度，显示恢复提示。跳过太多内容时向上回到已捕获部分附近，再继续缓慢向下滚动。
4. 点“完成并预览”，停止采样、合成一次最终图片并按设置应用圆角，进入现有“图片与文字”预览。其“图片操作”支持复制图片、另存为、贴图；OCR / AI 仍须用户显式触发。
5. **Esc** 或“取消”清空缩略图、停止后续采样、使在途回复作废并清理引擎条带。关闭功能、开始另一张截图或安全状态变化也会取消。没有自动落盘、自动复制或自动发送。

## 实现与边界

### 采样与生命周期

- `Platform/ScrollRegionCapture.swift` 使用 **ScreenCaptureKit / SCScreenshotManager**，以 display filter **仅包含目标窗口**，`sourceRect` 为选区的显示器局部逻辑坐标，输出尺寸按该屏幕像素比例计算。因此本应用 HUD 和无关遮挡窗口不进入采样图像。
- 来源绑定窗口 ID、PID、原窗口几何、屏幕布局与缩放。冻结时与开始时窗口位置不一致、窗口移位 / 缩放 / 离开当前空间、前台应用离开来源、显示器布局变化、权限或安全检查失败，均停止并取消本次会话。
- `ScrollCaptureController` 串行执行“采样 → 后台拼接 → 更新缩略图 → 等待 250ms”。只有显式按 L 的会话会连续采样；不在启动、空闲或预览阶段监听屏幕。不会并行发起下一帧，也不会排队等待拼接。
- 保留现有严格安全输入检查；长截图入口需要辅助功能和屏幕录制权限，焦点无法安全检查时不启动。R3 的无 AX 普通窗口截图回退保持不变。采样前后、发布结果前和会话保护循环均检查状态。
- 完成不等待尚未返回的系统采样：取消采样任务，按 actor 边界完成已接受条带，迟到帧丢弃。`SCScreenshotManager` 已发出的系统请求没有强制终止接口；应用停止继续请求，其迟到图像不追加、不显示、不保存。取消时 actor 在取消检查点退出计算并释放条带、行特征、页脚和缩略图。
- `ScreenshotCoordinator` 只负责模式切换、窗口生命周期和最终输出；`ScrollCaptureHUD` 负责控制条 / Esc 监视器；`ScrollStitcher` actor 负责像素计算。进入长截图时先释放原冻结遮罩的全屏图像。

### 拼接

- 归一化为 sRGB RGBA。每行生成完整行摘要及最多 32 列 RGB 特征；优先确认完整重叠行的一致性，没有精确匹配时再比较行特征误差。搜索正反方向，保留零位移作为静止变化的候选，不将小范围动画或光标闪烁当作新内容。
- 要求至少 **24 行且不少于正文高度 1/4** 的重叠。精确匹配出现多个偏移、近似匹配候选过多 / 分数接近、信息不足、没有足够重叠时，不猜测位移。快速滚动但仍有足够重叠可接受；完全跳过重叠范围则提示返回，不能重建缺失内容。
- 固定头尾先由相同位置的行识别，再用已确认的移动对应关系排除普通空白页边距。固定区域每端最多搜索帧高 1/3；正文之外的更大固定区域建议直接从选区排除。页头只保留首次，页脚仅保留末次；后续发现更完整的固定页脚时调整末尾条带边界。
- 保存已接受的新条带和上一帧行特征，不积攒完整采样帧。缩略图直接从条带抽样，最多 **180×540 像素**；失败 / 未变化帧复用缩略图，不为每次采样合成整张长图。完成时才分配最终连续图像。
- 大面积动画、动态重排、纯色或高重复页面仍有兼容性边界；不宣称对所有页面可靠。检测到不确定性时停止追加，允许恢复滚动或完成已有结果。真实浏览器和编辑器兼容性见下方待验收项。

### 上限与内存口径

| 限制 | 当前值与行为 |
| --- | --- |
| 最终高度 | 30,000 原始像素；到限不追加 |
| 接受帧数 | 32；重复 / 拒绝帧不计入 |
| 引擎像素工作预算 | 128 MiB；追加前校验，不满足则停在最后成功图片，仍可完成 |
| 单次系统采样 | 选区原始像素不超过 40 MiB；宽 ≤16,384、高 ≤8,192；引擎另校验实际行步长，过大选区拒绝 |
| 缩略图 | ≤180×540，内存中更新 |

预算覆盖输入图像及归一化、条带原始 backing（即使裁掉一部分也计入）、替换页脚、两份行特征、缩略缓冲，以及条带仍存在时的最终合成分配。计算取采样与合成两种峰值的较大值，另留缩略 / 管理余量。完成后先 reset 引擎，再进入圆角及既有输出流程。**128 MiB 是引擎的受控像素工作预算，不是整个 App RSS 或系统 WindowServer / 编解码器 / UI 显存的承诺**；本轮未实测真实采样的进程峰值。
