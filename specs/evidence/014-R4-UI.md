- **release 编译通过**：完成 DEBUG 边界后直接构建 release，正式代码未出现对 Mock 的残留依赖。
- **符号正反对照通过**：debug 中存在 `GalleryRenderer`、`GalleryWindowController`、`SettingsFixtures`、`ImagePreviewModel`、`ImagePreviewPrototype`、`SurfaceSample`；release 中全部不存在。检查保存到 `.build/r4-ui-review/{debug,release}-symbols.txt`，正式构建门禁另保存 `.build/app-release-symbols.txt`。
- **开发入口验证**：新增 `DevelopmentGalleryTests` 在 debug 测试宿主中直接调用与 CLI 相同的 `GalleryRenderer.render`。不运行 App/main，不创建生产监听器、不启动真实主程序；CLI 参数解析未改行为，构建脚本保留开发命令。
- **视觉等价**：修改前用现有 Gallery 离屏测试导出 158 张深浅色图；修改后调用正式 GalleryRenderer 导出同一注册表，逐张比较 PNG：156 张直接字节一致；两张通用设置首帧因渲染顺序不同存在少量光栅差异。用修改前相同设置入口复跑，42 张设置图全部字节一致。按相同入口比较合计 **158/158 字节一致**，详见 `image-comparison.txt`、`before/`、`after/`、`same-entry/`。导航类型声明另以原始文本核对，逐字节一致。
- **完整测试、签名构建、最终渲染**：日志 `.build/r4-ui-review/{test,build,render}.log`，实际退出码同名 `.exit`，三项均为 **0**。Swift Testing **203 项**及脚本内 XCTest/Rime/外壳检查通过。签名后的 `dist/RockType.app/Contents/MacOS/RockType` 再经 nm/demangle 检查，无 Gallery/Fixtures 类型；strings 中也没有 `--gallery` / `--render-gallery`，见 `packaged-symbols.txt`。
- 本任务只使用合成视图、测试与只读符号检查；没有安装/注册输入法、加载 LaunchAgent、运行主 App 二进制、模拟全局键盘、读取剪贴板或截取真实屏幕。
