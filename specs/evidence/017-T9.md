# SPEC-017 T9：翻译窗整体视觉精修

2026-10-12；`agent/ui` 开始前已 fast-forward 合并 main `d3d0649`（T1/T3/T8）；收尾再次 `git merge main`，仍为该提交，并在合并后重跑完整测试和构建。

## 实现与范围

| 用户反馈 | 实现 |
| --- | --- |
| 原文下面大片空白 | 使用 TextKit 按实际文字及编辑器宽度测量；一行按一行显示，默认最多四行；超过后原文区可滚动，也可展开到最多十二行。短原文不显示无效的展开按钮。保留原来的 IME、Return 和编辑回调。 |
| 语言条半宽、浮灰块 | 改为整宽细条，上下细分隔；左右语言区域等宽，⇄ 在中央。长文滚动使用 overlay scroller，避免滚动条槽让整条向左偏移；样式辅助视图不接收点击或加入无障碍树。 |
| 窗口不随内容收拢 | 用 SwiftUI 实际 header/content/footer 高度替代固定基数与字符数估算；长文仍限制在屏幕可见高度的 60%。保留宽度和位置记忆；显式调整的高度单独记为上限，短内容仍收拢，单纯移动不会锁住高度；后续调整使用窗口当前所在屏幕的边界。 |
| 词典与译文抢层次 | 翻译窗使用轻量 embedded 词典样式：更紧凑内边距、浅描边、无卡片阴影。词典是主要内容，初次单词译文是一行次级补充；完整译文仍用于复制/朗读，并可在 help 中查看。追问结果保持完整展示。 |
| 标题、标签、朗读/展开对不齐 | 标题与原文行共用对齐边距；原文/译文标签用 11pt 次级色，图标统一 14pt medium、28pt 控件尺寸、悬停与焦点态、help。 |
| 底部不齐 | 引擎菜单、朗读、替换、复制原文与复制译文共用一行和统一间距；长模型名截断并保留完整 help，主按钮不挤压换行。 |

生产修改仅在翻译窗视图、样式与 `TranslateWindowController` 的窗口布局/尺寸记忆部分。`SpeakButton`、`SourceReplacementButton` 只增加可选紧凑样式；`SourceReplacement.swift` 的替换服务部分没有修改。词典组件原来的独立样式保留。

未修改翻译状态/请求、语言路由、缓存、词典查询/解析、朗读服务、AX/剪贴板、权限或安全输入逻辑。保留现有 120ms 出现动画及减少动态效果分支；窗口尺寸直接更新，不叠加流式缩放动画。

全部为合成内容和注入服务。测试使用正式控制器及其 NSHostingView，立即隐藏自己的测试窗口，再从视图导出位图；不截取桌面、不读取真实选区、不发声、不启动主 App。

- `.build/t9/before/`：14 张，基于 `d3d0649` 的真实窗口尺寸。
- `.build/t9/after/`：16 张；深浅色 × 短句、词典、长文、原文展开、空态、错误提示、追问和新增 360pt 窄窗/长模型名。
- `.build/t9/index.html`：逐项对比；`short-comparison.png`、`dictionary-comparison.png`：相同比例拼图，不拉伸窗口高度。
