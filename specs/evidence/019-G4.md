# SPEC-019 G4 · 右键取消截图与样式测试隔离

基线：先将 `agent/xpc` 快进合并到 main `3eccf5a`，读取 FeatureSettings 已定契约。关联 FR-D1、FR-D2、NFR-4。只修改截图事件路由及相关测试，不改功能开关、输入法或设置界面。

## 行为

- 活动截图遮罩收到右键：未框选及已框选时消费该事件，调用与 Esc 相同的 `cancel()`，关闭所有遮罩并沿用原有浮窗恢复、来源焦点恢复和异步任务取消逻辑。
- 任一遮罩存在文字编辑（包括中文 marked text）时，右键交还 AppKit；不会走原来会提交文字的“点击编辑区外”路径。另一显示器上的右键同样不结束文字编辑。
- 非本次截图所属窗口、另存为面板保留右键原生行为。左键点击编辑区外仍提交文字。

## 偶发失败根因与复现

`AnnotationStyleTests.testToolbarStyleChangeIsRememberedOnlyForThatTool` 使用合成图片，但没有替换 `CaptureCanvas.allowed` 的默认实现。因此样式修改通过 `ScreenCapture.isReadable → SecureInput.status()` 查询**真实系统保护状态**；受保护或无法确认焦点时，`setStyle` 按生产规则取消且不写样式，导致期待的箭头样式和回调断言失败。

这条测试路径的 `toolStyles` 是每个画布独立的字典，`onStyleChange` 只是测试内数组回调，工具栏也只接收值和闭包，不访问 `SettingsStore.shared`。证据不支持“共享设置串写”，实际未隔离的是实时 AX/安全输入环境。

将原测试的 `allowed` 临时固定为 false，运行：

```sh
swift test --filter AnnotationStyleTests/testToolbarStyleChangeIsRememberedOnlyForThatTool
```

真实退出 **1**，稳定出现 2 个断言失败：箭头样式仍为默认值、回调为 `[]`。记录 `.build/g4/style-denied-before.log` 与 `.exit`。随后仅将合成样式测试的 allowed 固定为 true；生产保护逻辑不变。另加拒绝状态测试，确认取消发生、无样式回调且字典不被写入。没有修改系统权限、清空共享设置、增加等待或重试。

## 验证

- 右键回归在修复前真实退出 **1**：3 项测试中，取消及 marked text 保留场景共 10 个断言失败，见 `.build/g4/right-before.log`。
- 修复后定向检查 **24 项通过，退出 0**：样式、右键、文字/IME、遮罩生命周期及另存为，见 `.build/g4/focused.log`。
- 新测试使用两块合成离屏遮罩：覆盖框选前后右键关闭全部遮罩、不产生完成回调/历史条目；本屏与另一屏右键保留 marked text；左键仍提交；非所属画布不被取消。
- 另存为测试补查右键传递给原生面板，面板保持打开。既有 `CaptureEntryTests` 检查取消恢复浮窗、丢弃迟到采样；既有文字测试覆盖 Esc 与中文输入。
- 完整 `scripts/test.sh` / `scripts/build.sh`：均通过，真实退出码均为 **0**；修复后首次全量运行即通过，未靠重跑获得绿灯。`git diff --check` 通过。日志与退出码写入 `.build/g4/{test,build}.{log,exit}`。
