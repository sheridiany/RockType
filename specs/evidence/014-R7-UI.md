## 做了什么

- 落实 `docs/copy-audit.md` 中 **InputMethod/ 的 14 项**：简繁体菜单名称/省略号、部署失败提示、英文成功通知、三种语言的 RockType Pinyin 显示名。清单已标记落实，R6 原文与静态索引保留为历史快照；其他 22 项不代改。
- 同时补齐这些菜单项的英文显示值和英文通知标题 RockType，保留 `Squirrel`、`Logs...`、`Settings...` 等查找键；英文部署失败提示提供打开日志目录的下一步。学习菜单使用“引号”，PanelChecks 的既有断言同步更新。
- InputMethod 只改文案/本地化和图标资源/图标文件名，不改按键、候选、XPC、重试或状态逻辑；Voice 与 VoiceWorker 未改。
- **发现并修复真实图标问题**：Icon Composer 的 Dark/Tinted 层级实色覆盖会给开放的描边 SVG 填色，导致 R 字内部空白被填实。App 与输入法两份 `.icon` 移除多余的层级覆盖，继续使用原 SVG 白色描边；保留两种底色、字形几何、玻璃/阴影配置。没有重绘品牌图形。
- 输入法源 Info.plist 的 `RimeIcon.icns` 与实际产物 `Rime.icns` 不一致，改为实际资源名（actool 先前会在构建时覆盖成正确值）。两份 SVG 的内部 path id 清理为 `rocktype-r`，不影响外观。
- App 菜单栏绘图函数仅从 private 改为模块内可见，让测试调用真实工厂；函数体和模板行为不变。没有为矢量菜单图重复添加 PNG/@2x 文件。
