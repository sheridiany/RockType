## 接口与边界（供 T8）

```swift
let lookup = WordLookup() // @MainActor；默认 SecureInput.status() == .allowed
let definition = await lookup.lookup(sourceText) // WordLookup.Definition?，取消/保护/未命中均 nil
if let definition {
    WordDefinitionCard(definition: definition)
}
```

`Definition` 为 Sendable/Equatable 值，包含 `term: String`、`pronunciation: String?`、`senses: [Sense]`；`Sense` 包含 `partOfSpeech: String?` 与 `meaning: String`。T8 应在绑定原文的可取消 task 中查询；原文变化、保护状态变化或关闭窗口时取消任务并清空已显示值。服务不持有窗口、无共享结果状态，不自行创建窗口或争抢焦点。可注入 `allowed` 与异步 `provider` 做确定性验证。

- 输入按英文 A–Z/a–z 与单个词内连字符校验，最多 3 词，连续水平空白归一化；接受常见 Unicode 连字符并归一为 `-`。不接受数字、标点、撇号、内部换行或非英文字母。原输入最多 256 UTF-8 字节，归一化后最多 96 字符。
- 默认 provider 使用公开的 `CoreServices.DCSCopyTextDefinition(nil, term, 全词 UTF-16 range)`。独立 actor 在非 UI executor 上串行执行同步词典 API；调用前、排队后、返回后检查取消/保护。没有网络/AI 分支、日志、缓存或内容持久化，也不启用/下载词典。
- 系统词典返回的是非结构化纯文本，格式取决于本机词典。解析明确的 `/音标/`、`|音标|` 或方括号音标，过滤语法注记；识别常见完整/缩写词性并本地化标签；按编号、项目符号/换行取前三条释义，移除常见例句与词源尾部。识别不到的字段留空，未知格式保留释义文本，不生成音标/释义。每条最多 260 字符，输入词典正文最多 64 KiB。
- 卡片使用 Tokens、8pt 间距、12pt 圆角、细描边与仅作用于卡片背景的柔和阴影。原词与释义可选中，音标/词性为次级色；每条最多显示三行，悬停可看组件保留的释义。被动显示组件不添加窗口快捷键或自主动效；窗口出现/消失由 T8 所属窗口控制。
