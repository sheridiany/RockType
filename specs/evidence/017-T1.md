# SPEC-017 T1 · 翻译专用窗

- 基线：`agent/platform` 已快进合并 main `ca70071`；未安装、注册、推送。
- 新增独立 TranslateWindowState / Controller / View。工具栏、固定/自定义翻译快捷键、OCR 文本翻译、翻译历史共用专窗；其他文本/图像结果沿用通用窗。
- 原文默认 3–4 行，可展开、编辑；500ms 防抖或回车重翻，Shift-Return 换行。编辑立即取消旧请求、清除旧结果；组字不发送，重翻创建新会话。
- 源/目标语言、对调、目标记忆、临时引擎切换、实际返回模型、复制、折叠追问。自定义翻译动作以文本输入且包含 `{{target}}` 判定，保留其提示词/模型。
- Apple 优先复用既有 XPC 自动检测与回退契约；手选源语言明确切换 AI，切回 Apple 恢复自动检测。自定义提示词仅用 AI，避免 Apple 忽略指令。已有配置不被窗口内引擎选择改写。
- 默认宽 420，自动高度最多屏幕可见区 60%，拖动/调整后仅记忆几何；12pt 圆角、Tokens 色板、≤120ms 出现、减少动态效果直接出现。非激活显示，编辑时才允许 key。Esc/⌘C/⌘↩/⌘R/⌘L 仅在本窗口处理，尊重输入法组字和原文选中复制。
- `TranslateWindowSlots.dictionary(String)` / `.speech(String)` / `.close()` 留给 T2/T4/T8；没有提前接入查词或朗读。
