## A10：按职责分文件，状态所有权不动

采用同一个 `@MainActor final SquirrelInputController` 的 extension，避免此轮引入新所有者、状态机、队列或取消转发层。

| 文件 | 本轮后的职责 |
| --- | --- |
| `SquirrelInputController.swift`（980 → 384 行） | 所有状态、IMK 生命周期、设置/菜单、提交与标记文本；`handle` 保留 ObjC 参数桥接和 `MainActor.assumeIsolated` 后同步调用原事件体 |
| `SquirrelInputController+Events.swift` | 修饰事件顺序、按键/AI/Tab/Esc 分流、Rime dispatch、Shift 与和弦计时 |
| `SquirrelInputController+Candidates.swift` | 候选/翻页/光标动作、Rime context 展示、普通与 AI 快照、属性读取/设置 |
| `SquirrelInputController+Translation.swift` | 翻译/AI 请求、generation/快照校验、取消、译文栏状态及安全上屏 |
| `SquirrelView.swift`（799 → 382 行） | TextKit 视图状态、绘制入口、命中与可访问性 |
| `SquirrelView+Geometry.swift` | 文本范围矩形、高亮路径、圆角与分页图形计算 |

**刻意保留的边界**：session、generation、连接、所有计时器和 view 图形状态没有换所有者；初始化、激活、失焦、销毁、取消和 Rime C 内存释放顺序不变。语音填入已经独立在 `RoarkTVoiceServer` / `VoiceCommitTicket`，controller 的 `voiceClient` 门禁留在生命周期文件，本轮不再拆动它们。

跨文件 extension 所需成员由 file-private 改为模块内可见；类型仍为 internal final，不增加公共接口。只在原文件使用的预编辑文本/范围/光标等字段保留 private。这是**文件级职责整理**，不声称消除了状态机复杂度，也不为缩减行数建立新的对象层。

等价核对：逐方法比较搬迁前后的方法体，仅忽略行首尾空白。controller 原 42 个方法中，41 个方法体原样保留，`handle` 的原闭包体原样进入同步 `handleInputEvent`；view 相关 28 个方法体保留。记录 `.build/r4-ime/move-equivalence.log`。Xcode 的 Sources 与隔离 panel 检查脚本已纳入新文件。

## A07：唯一语音识别协议放 Shared

唯一普通文件现在是 `Shared/VoiceWorkerProtocol/VoiceWorkerProtocol.swift`。

- App 的 `App/Features/Voice/VoiceWorkerProtocol.swift` 指向该 Shared 文件。
- worker 的 `Services/VoiceWorker/Sources/RoarkTVoiceWorker/VoiceWorkerProtocol.swift` 也指向它。
- `Tests/VoiceWorkerSmoke/run.sh` 直接编译 Shared 文件，取消经 App 路径取协议的依赖。

采用轻量 Swift 源分组，避免与 `Shared/XPCProtocol` 的 ObjC target 混用语言；两个现有 target 继续编译同一文件。没有新增 Package、依赖或运行时，没有把 MLX 引入 App，也没有跨 GPL/MIT 搬实现。

协议文件与搬迁前 **字节一致**。保留 `@objc(RoarkTVoiceWorkerProtocol)` 以及：

- `prepareWithDirectory:reply:`
- `transcribeWithAudio:context:reply:`
- `shutdown`

参数、回复类型、音频格式、上下文预算、签名身份和服务行为均未改。两个源链接解析到同一实体，运行时 selector 测试及构建内签名 XPC smoke 均通过。
