## 实现

- **截图历史**：复制完成、快速保存、另存成功、贴图成功、预览/⇧C 确认输出后入库；冻结整屏、取消与失败不入库。默认仅内存最近 20 张；外部图片导入不加入截图历史，重新打开历史不重复记录。
- **OCR 缓存与搜索**：每张截图后台串行调用本机 Vision；图像与文字不上传。按当前 OCR 语言设置识别；缓存原文，预览编辑会覆盖同条缓存，后台 OCR 不覆盖用户修改。缓存记录上限 256 MiB（大图提前淘汰），单条 OCR 前 64 KiB；原图不因此缩小/裁切。OCR 尚未完成或失败的记录可重新打开预览识别。
- **面板**：菜单与 `⌃⌥H` 打开，缩略图网格、OCR 搜索、预览、贴图、复制图片、另存、删除、确认后一键清空；空态、载入/磁盘同步、错误与重试。复用预览与保存控制器。关闭预览不会把空文本回写到历史。
- **磁盘选项**：设置 → 截图追加开关，默认关闭；只追加可选设置字段，缺字段 JSON 可解码。开启后默认 20 张/7 天，可设 1–200 张/1–365 天，修改、启动、显示历史和每分钟清理过期/超限项。目录唯一来源为 `Identifiers.screenshotHistoryDirectory(home:)`：`~/Library/Application Support/RockType/ScreenshotHistory/`；UUID PNG + JSON 索引，没有数据库或新运行时。
- **串行持久化**：actor 负责编解码与文件 I/O；有代次、取消和 150ms 合并写入。图片/索引原子写入，目录 0700、文件 0600；每次重新读取实际文件属性，拒绝符号链接祖先，内容文件不跟随符号链接。磁盘读取限制 200 条、单 PNG 40 MiB/6400 万像素、总解码预算 256 MiB。索引有大小上限，不把错误路径或内容写到日志。关闭磁盘保存、删除、清空会删除对应磁盘副本；失败明确提示并允许重试，重试删除不重新载入旧内容。
- **生命周期/保护**：普通退出取消未完成的 OCR 并等待已有磁盘同步；未完成 OCR 不被误称已缓存。Secure Input、密码框或无法核验输入保护时拒绝入库/识别/缓存发布，保护变化取消 OCR、关闭历史面板；以前合法生成的历史保留。磁盘同步被保护阻止后，解除保护可刷新/重试，正常退出也尝试完成合法待写内容；不在保护状态下写缓存。清空、删除与旧任务迟到不会复活记录。全局“清除当前内容”清除默认临时历史；已开启磁盘保存的记录从历史面板显式清空。
- **卸载**：共用的 `UninstallData` 删除独立截图历史目录；临时 home 验证保留 `RockType` 下无关文件和其他输入法数据，拒绝链接重定向。没有运行真实卸载流程或开发卸载脚本。
- **贴图群组**：隐藏/显示全部保持位置、尺寸、透明度、锁定；关闭全部保留按原数量设置恢复的能力；循环切换焦点，目标退出鼠标穿透。保护与全局清理仍使用清除全部及恢复记录的路径。群组快捷键先结束截图遮罩，避免隐藏窗口的恢复流程重新显示用户刚隐藏的贴图。
- **新全局快捷键**：`⌃⌥H` 历史、`⌃⌥P` 隐藏/显示全部、`⌃⌥X` 关闭全部、`⌃⌥N` 下一张；与现有默认键互不重复。设置快捷键页沿用原有枚举驱动列表、修改/冲突/清除/恢复默认流程；缺新增键的设置使用默认，显式清除可跨 JSON 往返保留。
