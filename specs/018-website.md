## 参考结论（Claude 调研 Typeless / CleanShot X / Raycast / Bob）

- 首屏一句短主张 + 一句具体副标题 + 一个主按钮（下载）+ 次按钮（看看怎么用）；下方一行系统要求/签名。
- 每个能力一屏：短标题（4–8 字）+ 一句话 + **真实产品画面或动效**（不是图标卡片）。CleanShot“Make your point, fast”、Raycast“Don't repeat yourself”式短句。
- 用具体数字代替形容词（只用真实可证实的：本机识别不上传录音、Apple 离线翻译约 80ms 首字、OCR 评测 99.7%、截图历史 20 张、快捷键 Fn / ⌃1 / ⌃⌥T）。
- 隐私单独一屏（Typeless “Private by design”）：录音本机识别、密钥存钥匙串、密码框不取词、截图发给 AI 前必须确认、无账号无云端。
- “能用在哪里”：常用 App 图标横向滚动带（用文字徽标/中性图形，不使用他人商标图片）。
- 键盘快捷键用 `kbd` 键帽视觉，突出“键盘优先”。
- 结尾再一次下载 CTA。不得编造用户数、评价、媒体背书、评分。

## 页面结构与文案方向（可润色，保持克制、短句、中文为主）

1. 导航：RockType 字标 · 功能 · 隐私 · 更新日志 · GitHub · 下载按钮。
2. Hero：主张示例“打字、说话、截图，一个就够。”或“Mac 上更快的表达方式。”；副标题“中文输入法、本地语音、划词翻译与截图 OCR，合成一个原生 Mac 工具。”；主按钮“下载 macOS 版”，次按钮“看看怎么用”；下方小字“Apple Silicon · macOS 14+ · 已签名”。主视觉：深色桌面场景中候选窗+译文栏、语音胶囊、翻译窗叠放的合成画面（用真实离屏渲染图）。
3. 输入法：“打中文，顺手出英文。” 候选窗+译文栏画面，`Tab` 填入译文；全拼/小鹤双拼；输入法内 AI ⌥Tab。
4. 语音：“按住 Fn，说完就好。” 语音胶囊波形动效（CSS 动画还原 9 根电平条），本机识别、自动去口头禅、任何输入框可用。
5. 划词翻译：“选中，即译。” 翻译窗画面 + 工具栏；单词词典、朗读、替换原文、Apple 离线/AI 可切。
6. 截图与 OCR：“框选之后，什么都能做。” ⌃1、标注、贴图、长截图、OCR、图片翻译、二维码。
7. AI：“用你自己的模型。” 多服务商、按任务选模型、自定义动作与快捷键。
8. 隐私：“本机优先，不留痕迹。” 5–6 条事实。
9. 快捷键一览：键帽网格（Fn、⌃1、⌃⌥T、⌃⌥S、⌥Tab、Tab）。
10. 结尾 CTA：“现在就换一种方式打字。” + 下载。
11. 页脚：版本、隐私、更新日志、源码（GPL 输入法部分）、反馈、© Roarkist。

## 视觉要求

- 纯静态：HTML + CSS + 少量原生 JS，无构建步骤、无框架、无外部 CDN/字体（系统字体 `-apple-system, "PingFang SC"`）、无追踪脚本。
- 高级感：大字号紧字距标题、充足留白、12 列栅格最大宽 1120、深浅色自适应（深色为主视觉）、柔和渐变光晕背景、玻璃质感卡片、细描边；滚动进入轻微淡入上移（尊重 prefers-reduced-motion）。
- 产品画面使用仓库里真实的离屏渲染图（`specs/evidence/`、各 worktree `.build/` 中的 PNG，复制到 `website/assets/` 并压缩为 webp/png，每张 < 300KB），必要时新渲染更干净的展示图；不使用示例占位文字“合成”“Preview model”等。
- 移动端适配（≥ 360px）、可访问性（alt、对比度、键盘焦点）、Lighthouse 性能/可访问性尽量 ≥ 95。
- SEO：title、description、OG 图（1200×630，新做）、canonical 先用 `https://rocktype.roarkist.com/` 占位并在 README 标注待定域名。
- 下载链接：暂指向 `https://github.com/Roarkai/RockType/releases/latest` 并在 README 标“待发布确认”。
