## V1 语音条

参考 Typeless（首要）、Wispr Flow、Superwhisper、VoiceInk、Handy 的录音指示条：屏幕底部居中的小胶囊，几乎没有文字，靠波形和动效表达状态。

- 删除实时预览（R5-IME 的 HUD 增量预览 UI 与相关状态）。识别/分段逻辑本身保留，只是不再显示文字。
- 尺寸：录音时胶囊约 宽 ≤ 120pt、高 ≈ 32pt（可微调），不显示“正在录音”等文字和计时器；只有居中的音量波形（随真实电平跳动的 5–9 根圆角竖条，静音时低平呼吸）。可保留一个很小的取消按钮，悬停时才出现。
- 状态用形态区分而非长文字：模型准备中 = 波形条做从左到右的流光/脉冲；识别中/润色中 = 波形收拢成跳动的三点或旋转流光；成功 = 短暂对勾后收起；无有效声音 = 轻微左右摇晃后收起。
- 动效：出现时从底部弹出 + 缩放（spring，~0.25s），消失时淡出缩小；状态切换宽度平滑过渡；全部尊重“减少动态效果”设置。
- 视觉：深色半透明胶囊（浅/深色模式都用深底更像 Typeless），细描边、柔和阴影；位置屏幕底部居中、Dock 上方，跟随当前活动屏幕。
- 错误/“未能填入”结果仍需能看到文字和复制按钮：此时才展开为卡片，其他状态不展开。
- 不影响打字路径、Secure Input 规则；更新 Gallery（DEBUG）里语音 HUD 各状态。
- 验收：test/build 退出码 0；离屏渲染各状态截图放 `.build/v1/`；真实 Fn/麦克风 待人工验证。

## I1 截图图标

- 范围：截图工具栏（`CaptureToolbar`）、编辑器、预览面板、贴图、历史、长截图 HUD 中的所有图标，统一一套。
- 风格要“硬朗”：线条更粗（SF Symbols 用 `.semibold`/`.bold` 权重或 `.fill` 变体统一）、几何感强、不用圆润/卡通的符号；图标尺寸统一（约 15pt）、按钮 32×30、选中态用实色底 + 反色图标；主操作“完成/复制”用强调色实底按钮，“取消”用中性。
- 重新挑选更贴切的符号，例如：选择 `cursorarrow.rays`/`arrow.up.left`、矩形 `rectangle`、圆角矩形 `app`、椭圆 `circle`、箭头 `arrow.up.right`、直线 `line.diagonal`、画笔 `pencil.tip`、荧光笔 `highlighter`、文字 `textformat`、马赛克 `checkerboard.rectangle`、序号 `1.circle`、橡皮擦 `eraser`、撤销/重做 `arrow.uturn.left/right`、OCR `text.viewfinder`、贴图 `pin`、保存 `square.and.arrow.down`、取消 `xmark`、完成 `checkmark`。以 macOS 14 可用为准，逐个确认符号存在。
- 把符号名集中到一个地方（如 `ScreenshotSymbols`），各界面引用，不再散落字符串。
- 工具栏整体：背景更实、圆角略小（~10）、分组之间用竖分隔线，深浅色都检查对比度。
- 验收：test/build 退出码 0；离屏渲染工具栏深浅色对比图放 `.build/i1/`（旧/新各一张）；真实交互待人工验证。
