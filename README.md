# RoarkT

macOS 上的个人输入与 AI 工具：双语输入法（候选旁直接给出译文）、本地语音输入、划词 AI 助手和截图工具，共享同一套翻译、AI、设置与权限。

由洛克输入法（RoType）与 RoarkTools 合并，以 Swift 重写。不兼容两个旧项目的用户数据。

当前状态：**M0 工程骨架（2026-10-11）**。开发约定见 [AGENTS.md](AGENTS.md)。
